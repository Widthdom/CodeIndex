## English

- **C# calls inside lambdas returned by switch expressions are indexed again (#5085)** — positional-pattern suppression now distinguishes result terminators and expression continuations from nested positional clauses and valid pattern suffixes before following an arm arrow onto the next line, preserving qualified and unqualified calls in expression, block, parenthesized, multiline, nested-switch, and async lambdas while continuing to exclude genuine pattern heads, including guarded, nested, and contextual-keyword-designation patterns whose arrow is on the following line, from the call graph.

## 日本語

- **switch expression が返す lambda 内の C# call を再び index するようになりました (#5085)** — positional pattern の抑止処理は、arm arrow を次行まで追跡する前に result の終端や expression continuation と nested positional clause / 有効な pattern suffix を区別します。これにより expression、block、parenthesized、multiline、nested switch、async の各 lambda 内にある qualified / unqualified call を保持しつつ、次行に矢印がある guarded / nested / contextual-keyword-designation pattern を含む本物の pattern head は引き続き call graph から除外します。
