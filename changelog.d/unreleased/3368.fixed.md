## English

- **Export/import database path guards now use the stamped workspace case-sensitivity contract (#3368)** — archive and ctags output overlap checks now honor `workspace_path_case_sensitive` before falling back to the live filesystem path comparer, so case-sensitive APFS and other non-default volumes no longer inherit a macOS-wide case-insensitive heuristic.

## 日本語

- **export/import の DB パス保護が workspace の大小文字区別 stamp を使うようになりました (#3368)** — archive と ctags の出力先 overlap チェックは `workspace_path_case_sensitive` を優先し、取得できない場合だけ実ファイルシステムのパス比較へフォールバックするため、case-sensitive APFS などの非標準ボリュームで macOS 全体を case-insensitive とみなす heuristic を引き継がなくなりました。
