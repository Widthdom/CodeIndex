## English

- **Report bundles are overwrite-safe, provenance-scoped, and explicit about database membership (#4828)** — `cdidx report` now refuses an existing output unless `--overwrite` is supplied, correlates saved failures by opaque workspace/database identity, binary version, and timestamp while validating and disclosing their run ID, lists every archive member, and separates database inspection/diagnostics from the always-false database-member field while retaining `db_included` as a compatibility alias.

## 日本語

- **report bundle を上書き安全・provenance 限定にし、DB membership を明確化しました (#4828)** — `cdidx report` は `--overwrite` が無ければ既存出力を拒否し、保存済み failure を同梱する前に不透明な workspace / database identity、binary version、timestamp で相関し、run ID を検証・開示します。また全 archive member を列挙し、DB の検査・診断と常に false の DB member field を分離しつつ、`db_included` は互換 alias として維持します。
