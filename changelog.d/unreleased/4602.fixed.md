## English

- **Extractor registrations are now immutable and workspace-scoped (#4602)** — same-language plugins and patterns resolve from workspace snapshots with exposed built-in/user/workspace precedence; explicit-language graph gates, analysis, unused-symbol queries, status, and CLI/MCP language reporting use the indexed workspace snapshot; and generation-checked staged reloads, bounded LRU retention, and post-cancellation retirement prevent reloads, shutdown, or late plugin commits from leaking, resurrecting, or mutating another workspace's active extractors and plugin contexts.

## 日本語

- **extractor 登録を immutable かつ workspace-scoped にしました (#4602)** — 同じ language の plugin / pattern は built-in/user/workspace precedence を公開する workspace snapshot から解決され、明示 language の graph gate、analysis、unused-symbol query、status、CLI/MCP language reporting も index 対象 workspace の snapshot を使用します。世代検証付き staged reload、上限付き LRU 保持、cancel 完了後の retirement により、reload、shutdown、遅延 plugin commit が他 workspace の active extractor や plugin context を漏洩・復活・変更しません。
