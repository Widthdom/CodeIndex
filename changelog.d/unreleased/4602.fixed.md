## English

- **Extractor registrations are now immutable and workspace-scoped (#4602)** — same-language plugins and patterns resolve from workspace snapshots with exposed built-in/user/workspace precedence; reference-language purge, status, language reporting, and graph queries use the active snapshot; and bounded LRU retention plus terminal retirement prevents reloads, shutdown, or late plugin commits from leaking or mutating another workspace's active extractors and plugin contexts.

## 日本語

- **extractor 登録を immutable かつ workspace-scoped にしました (#4602)** — 同じ language の plugin / pattern は built-in/user/workspace precedence を公開する workspace snapshot から解決され、reference-language purge、status、language reporting、graph query も active snapshot を使用します。上限付き LRU 保持と terminal retirement により、reload、shutdown、遅延 plugin commit が他 workspace の active extractor や plugin context を漏洩・変更しません。
