## English

- **Inspect JSON supports nested collection field projections (#5098)** — `cdidx inspect --fields` can now select one-level leaves such as `definitions.name`, `references.path`, and `callers.line`, while preserving response metadata, compact and byte-bounded behavior, definition-body recovery fields, deterministic parent/alias/order semantics, typed unknown-field errors, and a queryless `--fields list` catalog.

## 日本語

- **inspect JSON で collection の nested field projection に対応しました (#5098)** — `cdidx inspect --fields` で `definitions.name`、`references.path`、`callers.line` など 1 階層の leaf を選択できるようになりました。response metadata、compact / byte 上限制御、definition body の recovery field、決定的な parent / alias / 順序の規則、未知 field の型付き error、query 不要の `--fields list` catalog も維持します。
