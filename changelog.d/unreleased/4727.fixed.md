## English

- **`analyze_symbol` now infers graph language from consistent reference evidence when definitions are missing (#4727)** — definition-free results expose graph-language source, confidence, candidates, and conflict metadata, infer support only when reference/caller/callee evidence agrees on one language, and leave mixed-language evidence unresolved.

## 日本語

- **定義がない場合に `analyze_symbol` が一貫した参照 evidence から graph language を推論するようになりました (#4727)** — 定義がない結果では graph language の由来、信頼度、候補、競合 metadata を公開し、reference/caller/callee evidence が1言語で一致するときだけ support を推論し、複数言語が混在する場合は未確定のままにします。
