## English

- **Bounded NDJSON streams now end explicitly and report partial results (#4561)** — Plain and recipe/audit `search` reserves byte budget for a terminal record with authoritative or lower-bound counts, selection/interruption reasons, limits, omissions, and recovery guidance; `symbols` and `files` keep their raw discovery stream shape, including an empty stream for zero results. Byte-capped partial output exits with code 11 unless callers explicitly pass `--allow-partial`; unbudgeted diagnostics and envelope serialization are rejected. JSON envelopes preserve any stream terminal in dedicated metadata instead of counting it as a result row.
