## English

- **Bounded NDJSON streams now end explicitly and report partial results (#4561)** — `search`, `symbols`, and `files` reserve byte budget for a terminal record with counts, truncation reasons, limits, omissions, and recovery guidance. Byte-capped partial output exits with code 11 unless callers explicitly pass `--allow-partial`.
