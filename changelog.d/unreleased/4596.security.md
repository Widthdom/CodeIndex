## English

- **Plugin and hook DLLs now cross one secure filesystem boundary before execution (#4596)** — Default and overridden extension directories validate ownership, writable modes, every ancestor, containment, and regular-file leaves. Accepted bytes are hashed into private read-only staging before assembly load, preventing unsafe-directory and validation-to-load rename swaps. Windows CI gives its dedicated temp root a protected current-user ACL so extension fixtures exercise the same boundary without inheriting shared runner permissions.

## 日本語

- **plugin / hook DLL は実行前に単一の安全な filesystem boundary を通過するようになりました (#4596)** — 既定および override の extension directory で owner、writable mode、全祖先、containment、regular-file leaf を検証します。受理した bytes は assembly load 前に private read-only staging へ hash 付きで固定し、unsafe directory と validation-to-load 間の rename swap を防ぎます。Windows CI の専用 temp root には current-user 限定の protected ACL を設定し、shared runner permission を継承せず同じ boundary を extension fixture で検証します。
