## English

- **Installer release inputs now have archive and extraction safety budgets (#4605)** — release archive and metadata downloads have byte caps; archives exceeding member-count, declared-size, expanded-stream, compression-ratio, or actual extracted-size limits are rejected; link and unsupported entry types are forbidden; and extraction uses private staging permissions with safe ownership and mode flags.

## 日本語

- **installer の release input に archive / extraction safety budget を追加しました (#4605)** — release archive と metadata download に byte 上限を設け、member 数、宣言 size、expanded stream、compression ratio、または実展開 size の上限を超える archive を拒否します。link と未対応 entry type を禁止し、private staging permission と安全な owner / mode flag で展開します。
