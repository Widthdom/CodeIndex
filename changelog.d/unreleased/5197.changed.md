## English

- **Large dependency cycles are now bounded and actionable (#5197)** — CLI and MCP dependency-cycle results retain authoritative SCC sizes, totals, evidence breakdowns, largest-component details, current-page omission totals, and file-level grouping metadata while materializing only 50 nodes per component by default across human, JSON, DOT, GraphML, and JSON graph output. Compact summaries and explicit raw expansion are available, and C# noise suppression uses only current reference-identity metadata to remove unresolved, ambiguous, or resolved same-name non-target candidates while preserving confirmed targets and failing closed for stale or absent identity contracts.
