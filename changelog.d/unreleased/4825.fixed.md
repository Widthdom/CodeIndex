## English

- **C# type references now resolve only to compatible type-like symbols (#4825)** — C# `type_reference` rows now require a type-like target with matching generic arity, so framework types such as `Action<T>` and `Stream` no longer bind to unrelated same-name properties or create false dependency edges. References without a compatible indexed type remain unresolved, while uppercase property receivers retain their real member dependencies across partial-class files.

## 日本語

- **C# の型参照を互換性のある型相当 symbol だけに解決するようにしました (#4825)** — C# の `type_reference` row は型相当の target と一致する generic arity を必須とするようになり、`Action<T>` や `Stream` などの framework 型が無関係な同名 property に結び付いて偽の dependency edge を作らなくなりました。適合する index 済み型がない reference は unresolved のままとしつつ、大文字で始まる property receiver の実在する member dependency は partial class の別ファイル間でも維持します。
