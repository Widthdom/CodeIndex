## 日本語

- **language-map override の読み取り失敗が diagnostics として出るようになりました (#3472)** -
  読み取れない `.cdidx-langmap.yaml` は成功した空の override file として扱わず、
  warning を出して skip します。後続の読み取り可能な override file は引き続き読み込みます。
