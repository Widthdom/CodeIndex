## English

- **Bounded aggregate HTTP MCP request-body memory (#4548)** — HTTP request bodies now reserve a configurable process-wide byte budget before known-length reads and throughout unknown-length streaming, queueing, execution, and response completion. If canceled MCP work does not stop cooperatively, its reservation remains charged until that work actually completes. Saturation returns a classified HTTP 429, invalid per-request/budget combinations fail startup, health reports effective and live usage, and every terminal failure or shutdown path releases its reservation exactly once.

## 日本語
