## English

- **Installer reuse now revalidates installed release artifacts (#4607)** — installer dependencies are declared in one truthful preflight list including `find`, and the payload manifest is persisted with an independently authenticated release checksum receipt. No-version reruns reauthenticate that receipt and manifest before rehashing the binary, metadata, native runtime, and notices. Missing or changed artifacts are reported by name before a fully downloaded, staged replacement uses the existing rollback-capable promotion path.

## 日本語

- **installer の再利用時に installed release artifact を再検証するようになりました (#4607)** — `find` を含む installer dependency を1つの正確な preflight list に集約し、payload manifest を独立に認証済みの release checksum receipt と一緒に保存します。version 指定なしの再実行では、receipt と manifest を再認証してから binary、metadata、native runtime、notice を再ハッシュし、欠落・変更した artifact を名前付きで報告します。replacement は完全に download/stage してから既存の rollback 対応 promotion path で配置します。
