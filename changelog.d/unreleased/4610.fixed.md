## English

- **Valid PostgreSQL table, recursive CTE, and `RETURNS TABLE` files no longer abort SQL extraction (#4610)** — `RETURNS TABLE` result columns now use bounded, quote-aware parenthesis scanning instead of a capture-group range, so supported symbols and references remain indexable when these common PostgreSQL constructs appear separately or together.

## 日本語

- **有効な PostgreSQL の table、recursive CTE、`RETURNS TABLE` を含むファイルで SQL 抽出が中断しなくなりました (#4610)** — `RETURNS TABLE` の戻り列を capture group の範囲ではなく上限付き・quote-aware な括弧走査で解析するため、これらの一般的な PostgreSQL 構文が単独または同時に現れても、対応する symbol と reference を index できます。
