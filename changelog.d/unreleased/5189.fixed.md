## English

- **C# constructor calls through `using` aliases now retain authoritative positional arity (#5189, regression coverage for #5159)** — Resolution anchors the lexical alias token with its persisted source column and span while retaining the canonical target identity and qualifier, so one-, two-, and three-parameter constructors produce isolated reference and caller evidence. Nested and bounded multiline calls are supported; named arguments, binding-sensitive constructor families, raw strings, and malformed syntax remain conservative. The updated C# extractor contract automatically refreshes unchanged C# files on the next index run.

## 日本語

- **C# の `using` alias 経由の constructor call で authoritative な位置引数 arity を維持するよう修正しました (#5189、#5159 の回帰 coverage)** — 永続化した source column と span で字句上の alias token を特定しつつ、canonical target identity と qualifier を保持するため、1・2・3 parameter constructor の reference / caller evidence を分離できます。nested call と上限付き multiline call に対応し、named argument、binding-sensitive な constructor family、raw string、不正構文は保守的に曖昧なままにします。更新した C# extractor contract により、次回の index 実行時に未変更の C# file も自動的に refresh されます。
