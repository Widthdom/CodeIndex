## English

- **C# constructor calls through `using` aliases now retain authoritative positional arity (#5189, regression coverage for #5159)** — Resolution preserves the physical source line and anchors direct or lexical-alias tokens with their persisted source column and span while retaining the canonical target identity and qualifier, so one-, two-, and three-parameter constructors produce isolated reference and caller evidence. Nested and bounded multiline calls, simple conditional expressions, `global::` qualifiers, and escaped keyword parameter names are supported; named arguments, primary/explicit binding-sensitive constructor families, raw strings, interpolated strings with embedded expressions, ambiguous relational/generic angle syntax, malformed spans, and malformed calls remain conservative. The updated C# extractor contract automatically refreshes unchanged C# files on the next index run.

## 日本語

- **C# の `using` alias 経由の constructor call で authoritative な位置引数 arity を維持するよう修正しました (#5189、#5159 の回帰 coverage)** — 物理 source line を維持し、永続化した source column と span で direct / 字句上の alias token を特定しつつ、canonical target identity と qualifier を保持するため、1・2・3 parameter constructor の reference / caller evidence を分離できます。nested call、上限付き multiline call、単純な conditional expression、`global::` qualifier、escaped keyword の parameter 名に対応し、named argument、primary / explicit を含む binding-sensitive な constructor family、raw string、embedded expression を含む interpolated string、曖昧な relational / generic angle syntax、不正な span / call は保守的に曖昧なままにします。更新した C# extractor contract により、次回の index 実行時に未変更の C# file も自動的に refresh されます。
