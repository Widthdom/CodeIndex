## English

- **Hook discovery and execution now stay entirely inside bounded workers (#4600)** — Assembly loading, module initialization, type discovery, constructor validation, construction, and callbacks no longer create a parent load context. Bounded discovery manifests assign stable IDs from the assembly fingerprint, source-path identity, and full type name; status and hook diagnostics expose those IDs, and timeout disablement no longer collides across DLLs that define the same type name.

## 日本語

- **hook discoveryとexecutionはbounded worker内だけで完結するようになりました (#4600)** — assembly load、module initialization、type discovery、constructor validation、construction、callbackはparent load contextを作成しません。bounded discovery manifestはassembly fingerprint、source-path identity、full type nameからstable IDを割り当て、statusとhook diagnosticがそのIDを公開します。同じtype nameを定義する別DLL同士でtimeout disablementが衝突することもありません。
