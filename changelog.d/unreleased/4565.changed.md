## English

- **`files` positional globs now use path-filter semantics (#4565)** — quoted positional values containing an unescaped `*` or `?`, including recursive patterns such as `**/*.cs`, now behave like `--path <glob>` instead of returning a misleading filename-query miss.

## 日本語

- **`files` の positional glob が path filter として扱われるようになりました (#4565)** — quote された positional 値にエスケープされていない `*` または `?` が含まれる場合、`**/*.cs` のような recursive pattern を含めて `--path <glob>` と同じように扱い、filename query として誤解を招く miss を返さなくなりました。
