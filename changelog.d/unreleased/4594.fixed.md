## English

- **Watch now reconciles the initial-scan handoff before reporting ready (#4594)** — the filesystem watcher subscribes before a startup reconciliation scan, drains the buffered startup generation, and emits `watching` only after every startup sub-run succeeds. A failed startup generation exits non-zero instead of discarding the edit and declaring a stale watcher ready.

## 日本語

- **watch が ready を報告する前に初回 scan の handoff を reconciliation するようになりました (#4594)** — filesystem watcher を startup reconciliation scan より先に subscribe し、すべての startup sub-run が成功して buffer 済み startup generation を適用した場合だけ `watching` を出力します。失敗した startup generation は編集を捨てて stale な watcher を ready と宣言せず、non-zero exit で終了します。
