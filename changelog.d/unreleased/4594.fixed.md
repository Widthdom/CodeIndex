## English

- **Watch now reconciles the initial-scan handoff before reporting ready (#4594)** — the filesystem watcher subscribes before a startup reconciliation scan, drains the buffered startup generation, and emits `watching` only after those changes are applied, so edits made between the initial scan and watcher startup cannot leave the database silently stale.

## 日本語

- **watch が ready を報告する前に初回 scan の handoff を reconciliation するようになりました (#4594)** — filesystem watcher を startup reconciliation scan より先に subscribe し、buffer 済み startup generation を適用してから `watching` を出力するため、初回 scan と watcher startup の間の編集で database が暗黙に stale のまま残ることを防ぎます。
