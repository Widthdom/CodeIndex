## English

- **Import staging databases are private before extraction begins (#5185)** — `cdidx import` now creates same-filesystem staging databases with collision-rejecting `CreateNew` and owner-only POSIX permissions before writing the first archive byte, then re-hardens the database and any WAL/SHM sidecars through validation, trust rewriting, optional path pruning, rollback-backup creation, and atomic replacement.

## 日本語

- **import staging database を extraction 開始前から private にしました (#5185)** — `cdidx import` は、最初の archive byte を書く前に、同一 filesystem 上の staging database を衝突を拒否する `CreateNew` と owner-only POSIX permission で作成し、validation、trust rewrite、任意の path pruning、rollback backup 作成、atomic replacement を通して database と WAL/SHM sidecar を再 hardening するようになりました。
