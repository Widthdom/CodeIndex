## English

- **MCP metrics writes are now non-blocking and recoverable (#4552)** — metrics events enter a bounded background queue, flush in batches, account for dropped events, and retry later batches with capped exponential backoff. MCP status and ping diagnostics expose queue, failure, and recovery health, while the first runtime failure emits one bounded warning.

## 日本語

- **MCP メトリクス書き込みを non-blocking かつ復旧可能にしました (#4552)** — メトリクスイベントを bounded background queue へ送り、batch 単位で flush し、drop 件数を記録しながら後続 batch を上限付き exponential backoff で再試行します。MCP status / ping 診断で queue・失敗・復旧状態を確認でき、最初の実行時失敗では bounded warning を一度だけ出力します。
