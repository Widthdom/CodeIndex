## English

- **`.m` and `.pl` now use conservative language classification (#4612)** — authoritative shebangs, bounded strong content markers, and bounded project markers distinguish Objective-C/MATLAB and Perl/Prolog; marker-only scoped updates reclassify dependent files, zero-arity Prolog rules and DCGs are recognized, and an incomplete final code point at the bounded read boundary is decoded safely. Weak or conflicting evidence remains explicit as `ambiguous_m` / `ambiguous_pl`, while shared language registries, query aliases, and new MATLAB and Prolog symbol extractors expose the detected languages without overstating reference or graph support.

## 日本語

- **`.m` と `.pl` を保守的に言語分類するようにしました (#4612)** — authoritative shebang、上限付きの強い content marker、上限付き project marker により Objective-C/MATLAB と Perl/Prolog を区別します。marker だけを対象にした scoped update でも依存ファイルを再分類し、zero-arity Prolog rule / DCG を認識して、上限付き読み取りの末尾で code point が途中になっても安全に decode します。弱い証拠や競合は `ambiguous_m` / `ambiguous_pl` として明示し、共有 language registry、query alias、新しい MATLAB / Prolog symbol extractor は reference / graph 対応を過大表示せず検出言語を公開します。
