## English

- **`excerpt` now accepts line-only focus (#4747)** — CLI `--focus-line` and MCP `focusLine` no longer require a focus column. When the column is omitted, long-line clamping keeps the leading window; explicit focus lengths still require a column.

## 日本語

- **`excerpt` が行だけのフォーカス指定を受け付けるようになりました (#4747)** — CLI の `--focus-line` と MCP の `focusLine` は、フォーカス列なしでも使用できます。列を省略した場合、長い行の切り詰めでは先頭側の window を維持し、明示的なフォーカス長には引き続き列指定が必要です。
