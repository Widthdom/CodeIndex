## English

- **Multi named-query searches now honor compact projection (#4584)** — `search` now serializes every named query as lightweight `{file,line}` rows under `--format compact`, while preserving query names, query text, per-query counts, truncation metadata, and the aggregate JSON byte cap.

## 日本語

- **複数 named-query の search が compact projection を正しく適用するようになりました (#4584)** — `search --format compact` は各 named query を軽量な `{file,line}` row としてシリアライズし、query 名、query 文字列、query ごとの件数、truncation metadata、レスポンス全体の JSON byte cap も維持します。
