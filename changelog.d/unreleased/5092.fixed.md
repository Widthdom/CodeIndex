## English

- Fixed `vacuum --json` to read each logical PRAGMA group from one SQLite snapshot while measuring the requested main/WAL/SHM file set from a stable source observation. Real execution refreshes physical sizes after command-owned SQLite handles close, and dry-run keeps its source file set separate from the private query snapshot. An unchanged raw source generation remains eligible, as does a hot-WAL-to-zero-WAL checkpoint representation with the same logical size signature; the latter preserves coherent size metrics without asserting application-data generation identity. If a concurrent writer changes that signature or produces another incompatible raw generation, every physical after field and compatibility alias is unavailable and WAL guidance is `unknown` instead of mixing size metrics.

## 日本語

- `vacuum --json` が論理 PRAGMA の各 group を1つの SQLite snapshot から読み取りつつ、指定元の main/WAL/SHM file set を安定した source observation から計測するよう修正しました。実行時は command 所有の SQLite handle を閉じた後に物理 size を再取得し、dry-run では source file set と private query snapshot を分離します。raw source 世代が不変な場合に加え、logical size signature が同じ hot-WAL から zero-WAL への checkpoint 表現も採用対象とします。後者は一貫した size metrics を保ちますが、application-data 世代の同一性までは保証しません。並行 writer がその signature を変更した場合、または互換性のない別の raw 世代になった場合は、size metrics を混在させず、すべての物理 after field と互換 alias を unavailable、WAL guidance を `unknown` として報告します。
