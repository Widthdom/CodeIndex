## English

- **Hook installs can now be previewed and report idempotent outcomes (#4716)** — `cdidx hooks install --dry-run` shows the planned create, managed replacement, custom-hook chain, or no-op action together with the managed hook without changing files. Real installs now distinguish `installed`, `updated`, and `already_installed`, and exact reruns leave the existing hook untouched.

## 日本語

- **hook install のプレビューと冪等な結果判定を追加しました (#4716)** — `cdidx hooks install --dry-run` はファイルを変更せず、予定される create、managed replacement、custom-hook chain、no-op の操作と managed hook を表示します。実際のインストールは `installed`、`updated`、`already_installed` を区別し、同一内容での再実行では既存 hook を書き換えません。
