## English

- **Audit recipes can now emit bounded SARIF findings (#4715)** — `search --recipe <name> --format sarif` preserves `recipe/query` rule identity, source locations, severity and confidence, conservative truncation metadata, and stable result fingerprints while respecting per-query and total result limits; unsupported row selectors are rejected instead of being silently ignored.

## 日本語

- **audit recipe から上限付き SARIF finding を出力できるようになりました (#4715)** — `search --recipe <name> --format sarif` は query ごと・全体の result limit を守りながら、`recipe/query` rule identity、source location、severity と confidence、保守的な truncation metadata、安定した result fingerprint を保持し、未対応の row selector は黙って無視せず拒否します。
