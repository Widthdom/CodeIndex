## English

- **State-changing MCP notifications now authenticate before mutating server state (#4537)** — cancellation, roots invalidation, shutdown, and exit notifications pass through the configured authentication gate; denied notifications remain response-free, emit a bounded local diagnostic, and leave server state unchanged.

## 日本語

- **state-changing MCP notification が server state を変更する前に認証されるようになりました (#4537)** — cancellation、roots invalidation、shutdown、exit の各 notification は設定済み認証ゲートを通り、拒否時は応答を返さず bounded なローカル診断だけを残して server state を変更しません。
