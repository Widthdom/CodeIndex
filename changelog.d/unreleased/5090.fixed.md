## English

- **GitHub duplicate preflight now traverses large issue histories with cursor pagination (#5090)** — `CDIDX_GITHUB_TOKEN`-authenticated live issue-draft preflight uses bounded GraphQL cursors for the selected open, closed, or all history, deduplicates page-boundary nodes, rejects missing or repeated cursors, and stops at the existing evidence limit. Authentication, permission, validation, rate-limit, timeout, transient, transport, response, and pagination failures now remain fail-closed runtime errors instead of CLI usage errors or "no duplicate" results.
