## English

- **Plugin code now executes only after metadata validation and inside a bounded worker (#4598)** — cdidx checks the plugin marker and API range without loading the DLL, then isolates assembly loading, construction, and symbol/reference extraction behind wall-clock, working-set, and protocol-output limits. Load failures are cached by content fingerprint, so repaired partial copies are retried while unchanged failures do not repeatedly execute.

## 日本語

- **plugin codeはmetadata検証後にbounded worker内だけで実行するようになりました (#4598)** — cdidxはDLLをloadせずにplugin markerとAPI rangeを検証し、assembly load、construction、symbol / reference extractionをwall-clock、working-set、protocol-output上限の内側へ隔離します。load失敗はcontent fingerprint単位でcacheするため、変更のない失敗を繰り返し実行せず、修復したpartial copyは再試行します。
