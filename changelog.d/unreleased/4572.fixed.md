## English

- **`inspect` now resolves indexed file paths and coordinates strictly (#4572)** — an exact indexed positional path now selects file inspection before symbol lookup, while explicit missing paths and lines beyond EOF return structured `E019_FILE_NOT_FOUND` or `E020_LINE_OUT_OF_RANGE` failures instead of unrelated nearest symbols.

## 日本語

- **`inspect` が indexed file path と座標を strict に解決するようになりました (#4572)** — indexed positional path の完全一致を symbol lookup より先に file inspection として扱い、明示した path の未検出や EOF 超過 line は無関係な nearest symbol ではなく、構造化された `E019_FILE_NOT_FOUND` / `E020_LINE_OUT_OF_RANGE` failure を返します。
