## English

- **Package normalization now uses durable unique temp replacements (#3996)** — the normalizer writes replacement archives through unique same-directory temp files, safely clears stale legacy temp files, flushes completed temp output, and flushes the parent directory after package replacement on Unix.

## 日本語

- **package normalization が durable な一意 temp replacement を使うようになりました (#3996)** — normalizer は同じ directory の一意な temp file 経由で replacement archive を書き込み、古い legacy temp file を安全に掃除し、完成した temp 出力を flush し、Unix では package 置換後に parent directory も flush します。
