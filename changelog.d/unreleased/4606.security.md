## English

- **MCP indexing authorization is now bound to the traversed directory identity (#4606)** — `index` captures a canonical root and filesystem identity, revalidates the original mapping and authorized boundary before directory and file access, rejects link or identity swaps with a structured permission error, and preserves the checked identity in structured results and audit JSONL.

## 日本語

- **MCP index の認可を実際に走査する directory identity に結び付けました (#4606)** — `index` は canonical root と filesystem identity を取得し、directory / file access 前に元の mapping と認可境界を再検証します。link または identity の差し替えは構造化 permission error で拒否し、検証済み identity を structured result と audit JSONL に保持します。
