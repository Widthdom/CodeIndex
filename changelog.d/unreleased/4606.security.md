## English

- **MCP indexing authorization is now bound to opened filesystem identities (#4606)** — `index` retains a no-follow root handle, performs handle-relative directory enumeration on Linux, macOS, and Windows, and validates pre-open, opened-handle, and post-open identities for file and sidecar reads. Language-map and pattern configuration is confined to an authorization-scoped project snapshot, link or identity swaps are rejected before content is consumed, and the checked root identity is preserved in structured results and post-authorization audit JSONL, including failure paths.

## 日本語

- **MCP index の認可を実際に開いた filesystem identity に結び付けました (#4606)** — `index` は no-follow の root handle を保持し、Linux / macOS / Windows で handle-relative な directory enumeration を行い、file / sidecar read で open 前・opened-handle・open 後の identity を検証します。language-map / pattern 設定を authorization-scoped な project snapshot に限定し、内容を利用する前に link / identity の差し替えを拒否し、検証済み root identity を structured result と、failure path を含む認可後の audit JSONL に保持します。
