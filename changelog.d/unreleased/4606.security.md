## English

- **MCP indexing authorization is now bound to opened filesystem identities (#4606)** — `index` retains a no-follow root handle and validates pre-open, opened-handle, and post-open identities for directory enumeration and file reads. Link or identity swaps are rejected before content is consumed, and the checked root identity is preserved in structured results and post-authorization audit JSONL, including failure paths.

## 日本語

- **MCP index の認可を実際に開いた filesystem identity に結び付けました (#4606)** — `index` は no-follow の root handle を保持し、directory enumeration と file read で open 前・opened-handle・open 後の identity を検証します。内容を利用する前に link / identity の差し替えを拒否し、検証済み root identity を structured result と、failure path を含む認可後の audit JSONL に保持します。
