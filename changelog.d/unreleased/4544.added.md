## English

- **MCP `resources/read` now supports bounded ranges and continuation (#4544)** — callers can select inclusive line ranges and a UTF-8 byte budget, while bounded defaults, explicit truncation metadata, and version-bound cursors keep large single-line and multi-line resources from being fully materialized before pagination.

## 日本語

- **MCP `resources/read` が上限付き range と continuation に対応しました (#4544)** — inclusive な行範囲と UTF-8 byte budget を指定でき、上限付きの既定値、明示的な truncation metadata、resource 版に結び付いた cursor により、長い単一行・複数行 resource を pagination 前に全文 materialize しなくなりました。
