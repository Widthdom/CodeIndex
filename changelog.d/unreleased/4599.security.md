## English

- **Git discovery now supports a validated portable override and rejects redirected metadata (#4599)** — `CDIDX_GIT_EXECUTABLE` accepts trusted absolute Git paths for Nix, custom-prefix, and portable installations only after POSIX owner/mode/sticky-ancestor or Windows owner/ACL checks and a bounded `git --version` probe. Untrusted symlink/reparse/device components, hard-linked metadata files, `.git` directories/files, worktree/common targets, and existing `info` / `exclude` / `hooks` descendants are rejected before atomic metadata writes.

## 日本語

- **Git 検出が検証済み portable override に対応し、redirect された metadata を拒否するようになりました (#4599)** — `CDIDX_GIT_EXECUTABLE` は Nix、custom-prefix、portable installation 向けの信頼済み絶対 Git path を POSIX の owner / mode / sticky ancestor または Windows の owner / ACL check と上限付き `git --version` probe の後だけ受理します。信頼されない symlink / reparse point / device component、hard-linked metadata file、`.git` directory / file、worktree / common target、および既存の `info` / `exclude` / `hooks` descendant は atomic な metadata 書込み前に拒否します。
