## English

- **Git discovery now supports a validated portable override and rejects redirected metadata (#4599)** — `CDIDX_GIT_EXECUTABLE` accepts trusted absolute Git paths for Nix, custom-prefix, and portable installations only after owner/mode/ancestor checks and a bounded `git --version` probe. Symlink/reparse/device `.git` directories, files, worktree/common targets, and existing `info` / `exclude` / `hooks` descendants are rejected before metadata writes.

## 日本語

- **Git 検出が検証済み portable override に対応し、redirect された metadata を拒否するようになりました (#4599)** — `CDIDX_GIT_EXECUTABLE` は Nix、custom-prefix、portable installation 向けの信頼済み絶対 Git path を owner / mode / ancestor check と上限付き `git --version` probe の後だけ受理します。symlink / reparse point / device の `.git` directory、file、worktree / common target、および既存の `info` / `exclude` / `hooks` descendant は metadata 書込み前に拒否します。
