## English

- **Git discovery now supports a validated portable override and rejects redirected metadata (#4599)** — `CDIDX_GIT_EXECUTABLE` accepts trusted absolute Git paths for Nix, custom-prefix, and portable installations with owner-only-write mode and executable diagnostics, while symlink/reparse/device `.git` directories, files, worktree targets, and common directories are rejected before metadata writes.

## 日本語

- **Git 検出が検証済み portable override に対応し、redirect された metadata を拒否するようになりました (#4599)** — `CDIDX_GIT_EXECUTABLE` は Nix、custom-prefix、portable installation 向けの信頼済み絶対 Git path を owner-only-write mode / executable 診断付きで受理し、symlink / reparse point / device の `.git` directory、file、worktree target、common directory は metadata 書込み前に拒否します。
