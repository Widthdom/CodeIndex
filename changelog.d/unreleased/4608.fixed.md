## English

- **Made C-versus-C++ `.h` detection lexical and budget-aware (#4608)** — header scoring now reuses the bounded C/C++ comment and string masker, ignores preprocessor payloads, and replaces the first-200-lines cutoff with a 48 KiB full-header budget plus contextual head/middle/tail sampling. Ambiguous results retain their detection source and confidence, while comment-only and macro-string C++ words no longer promote C headers.

## 日本語

- **`.h` の C/C++ 判定を字句解析ベースかつ budget-aware にしました (#4608)** — ヘッダー評価で上限付きの C/C++ コメント・文字列マスカーを再利用し、プリプロセッサのペイロードを無視します。先頭200行の打ち切りは、48 KiB までの全体評価と文脈付きの先頭・中央・末尾サンプリングへ置き換えました。曖昧な結果には判定元と信頼度を保持し、コメントだけ、またはマクロ文字列だけにある C++ 語彙で C ヘッダーが昇格しなくなりました。
