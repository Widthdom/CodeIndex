## English

- **Ctags exports now explain skipped symbols and support generated-code opt-in (#4720)** — `cdidx export ctags --json` reports bounded `skip_reason_counts` plus generated-code policy metadata, excludes generated files by default, accepts `--include-generated`, and degrades safely for legacy databases without generated-file metadata.

## 日本語

- **ctags export が skip した symbol の理由と generated-code opt-in を提供するようになりました (#4720)** — `cdidx export ctags --json` は上限付きの `skip_reason_counts` と generated-code policy metadata を報告し、既定では generated file を除外して `--include-generated` で含められます。また、generated-file metadata がない legacy database でも安全に縮退します。
