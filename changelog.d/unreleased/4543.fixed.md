## English

- **MCP transport teardown is now bounded across every exit path (#4543)** — EOF, malformed input, shutdown, and external cancellation share the bounded drain; the initiating HTTP shutdown notification completes its `204`, callbacks that start after the first drain snapshot are still bounded, inline control-write cancellation cannot bypass cleanup, and stdio output disposal waits for accepted late writers. Final diagnostics identify unfinished requests, writes, or callbacks.

## 日本語

- **MCP transport teardown をすべての終了経路で bounded にしました (#4543)** — EOF、不正 input、shutdown、external cancellation は共通の bounded drain を通り、shutdown 起点の HTTP notification は自身の `204` を完了します。初回 drain snapshot 後に開始した callback も上限内で待機し、inline control write 中の cancellation は cleanup を迂回せず、stdio output dispose は accepted late writer の完了まで待ちます。最終 diagnostic は未完了 request、write、callback を区別して報告します。
