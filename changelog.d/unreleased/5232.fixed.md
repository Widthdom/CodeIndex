## English

- **Ambiguous `goto --json` failures are now structured and bounded (#5232)** — Ambiguous definition lookups now return the shared versioned error envelope with stable `E029_QUERY_AMBIGUOUS`, `command: "goto"`, authoritative totals, structured narrowing guidance, and sanitized candidates bounded by count and UTF-8 bytes. Human diagnostics remain on stderr when JSON is not explicit, and callers still choose between narrowing and `--all` instead of an automatic ranked match. This restores the structured query-error contract introduced in #4319.
