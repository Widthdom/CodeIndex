## English

- **Installer downloads now have bounded network behavior and HTTPS-only public redirects (#4604)** — release/API transfers enforce configurable, validated connect, total, and low-speed timeouts with bounded retries; reject non-HTTPS public URLs and HTTPS-to-HTTP redirects; retain an explicit loopback-only HTTP self-test exception; and distinguish `network_timeout` from `protocol_rejected` failures.

## 日本語

- **installer download のネットワーク処理を有界化し、公開 redirect を HTTPS のみに制限しました (#4604)** — release/API 転送に検証済みで設定可能な connect・total・low-speed timeout と有界 retry を適用し、非 HTTPS の公開 URL と HTTPS から HTTP への redirect を拒否します。HTTP 例外は明示的な loopback self-test のみに限定し、`network_timeout` と `protocol_rejected` の失敗を区別します。
