## English

- **Suggestions now work with explicit databases in shared temporary roots (#4589)** — macOS/Linux shared-directory databases keep their sidecar and lock state in a deterministic owner-only user scope, while path and permission failures return structured `E021_SUGGESTION_STORE_UNAVAILABLE` diagnostics instead of exit 99.

## 日本語

- **共有 temporary root 直下の明示 database でも suggestions が動作するようになりました (#4589)** — macOS / Linux の共有 directory にある database の sidecar・lock state を deterministic な owner-only user scope に保存し、path / permission failure では exit 99 の代わりに structured な `E021_SUGGESTION_STORE_UNAVAILABLE` diagnostic を返します。
