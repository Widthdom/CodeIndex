## English

- **Added canonical `member_read` references for non-invoking C# member/value reads (#4894)** — new indexes distinguish qualified enum constants, constants, static readonly fields, static properties, and constant-pattern reads from true `call` edges. Callers, callees, and impact exclude these reads by default and expose explicit CLI `--include-member-reads` / MCP `includeMemberReads` compatibility controls; legacy indexes remain readable with their historical `call` rows.

## 日本語

- **呼び出しを伴わない C# member / value read 向けに canonical `member_read` reference を追加しました (#4894)** — 新しい index は修飾付き enum 定数、定数、static readonly field、static property、constant-pattern read を真の `call` edge と区別します。callers、callees、impact は既定でこれらを除外し、CLI `--include-member-reads` / MCP `includeMemberReads` の明示 compatibility control で復元できます。legacy index は従来の `call` row のまま引き続き読み取れます。
