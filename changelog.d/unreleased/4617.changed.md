## English

- **`languages` now separates extension and filename capabilities (#4617)** — CLI/MCP rows publish suffix-only `extensions`, literal `exact_filenames`, `<suffix>` filename-prefix patterns, and per-pattern provenance; language-map suffix overrides reassign affected exact filenames in the catalog just as they do during runtime detection. `legacy_patterns` retains the former combined list during a deprecation window, and round-trip tests verify every advertised typed pattern against actual detection.

## 日本語

- **`languages` の extension と filename capability を分離しました (#4617)** — CLI/MCP 行は suffix のみの `extensions`、literal な `exact_filenames`、`<suffix>` 付き filename-prefix pattern、pattern ごとの provenance を公開します。language-map suffix override は runtime detection と同様に、影響する exact filename を catalog 内でも再割り当てします。`legacy_patterns` は deprecation 期間中に従来の combined list を保持し、round-trip test は広告した全 typed pattern を実際の detection に対して検証します。
