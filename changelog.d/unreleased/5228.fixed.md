## English

- **C# semicolon-form positional records now return declaration bodies (#5228)** — `definition --body` now returns the complete declaration for semicolon-form `record`, `record class`, and `record struct` symbols, including multiline attributed, generic, inherited, constrained, anti-constrained, preprocessor-split, whitespace-qualified (`N . Base` and `Alias :: Base`), Unicode-named, source-Unicode-escaped, and longer-than-64-line forms. Indexed coordinates, projected output, truncation, and recovery metadata remain truthful; shared boundary lines are column-clipped from the record start for query, line, reference-position, and selector-based definition lookups so enclosing and following sibling text is excluded even when a multiline string closes earlier on the line, braced records keep their ranges when constraints wrap after `:`, ordinary types remain unchanged, malformed records no longer consume a following type or member declaration such as an instance constructor even after a base list, explicit-interface method or indexer, or fixed buffer, declarations or references before the record or after same-line or next-line terminators remain with their enclosing or following sibling scope even when another declaration precedes the record, whitespace separates generic arity, a type-parameter attribute contains a nested generic type, or a following same-line multiline method or type owns the reference in its opened body, cached record boundaries keep large-declaration reference extraction and symbol-container assignment linear, and the C# extractor contract refreshes unchanged files in existing indexes.

## 日本語

- **C# のセミコロン形式の位置 record が宣言本文を返すようになりました (#5228)** — `definition --body` は、複数行の属性、ジェネリック、継承、制約、`ref struct` 許可制約、preprocessor directive を挟む継続、空白付き修飾型（`N . Base` と `Alias :: Base`）、Unicode 名、source Unicode escape 名、および64行を超える形式を含むセミコロン形式の `record`、`record class`、`record struct` シンボルについて、宣言全体を返すようになりました。インデックス座標、投影出力、切り詰め、および復旧メタデータは実際の範囲を正しく示し、query、行、参照位置、および selector を使った definition lookup のいずれでも、同じ開始行の前方で複数行文字列が閉じている場合を含め、record の開始列からの切り出しによって境界行を共有する外側および後続 sibling の文字列を除外します。また、制約が `:` 後で改行されても波括弧形式の record の範囲を維持し、通常型を変更せず、不完全な record が base list 後のインスタンスコンストラクター、明示的 interface の method / indexer、fixed buffer を含む後続の型宣言やメンバー宣言を取り込みません。引数なし／位置 record では、前方に別の同一行宣言がある場合、ジェネリックのアリティの前に空白がある場合、型パラメーター属性内に nested generic 型がある場合、record 名が source Unicode escape で記述される場合も、record より前、または同一行／次行の終端より後にある宣言と参照を外側または後続の兄弟スコープに保ち、同じ行で後続する複数行 method または型の body 内にある参照はその sibling 自身に帰属させます。record boundary のキャッシュにより大きな宣言の参照抽出と symbol-container assignment も線形性を維持し、C# extractor contract の更新によって既存 index の未変更ファイルも再抽出されます。
