## English

- **MCP file resources support direct templates and bounded discovery filters (#4722)** — `resources/templates/list` now advertises `cdidx://file-path/{path}` for safe, percent-encoded resolution of a known repository-relative path while returning the canonical file-resource identity. `resources/list` adds bounded `path`, normalized `lang`, and opt-in `includeGenerated` filters, and its cursors reject filter changes between pages.

## 日本語

- **MCP file resource が direct template と有界な discovery filter に対応 (#4722)** — `resources/templates/list` が `cdidx://file-path/{path}` を公開し、canonical な file-resource identity を返しながら、既知のリポジトリ相対 path を安全に percent encode して直接解決できるようになりました。`resources/list` に有界な `path`、正規化される `lang`、明示指定の `includeGenerated` filter を追加し、ページ間で filter が変わった cursor は拒否します。
