## English

- **LSP stdio now exits promptly after shutdown/exit even when stdin remains open (#5086)** — the server stops scheduling input reads after the ordered `exit` notification, flushes the shutdown response first, and preserves the nonzero status for exit-before-shutdown without closing caller-owned streams.

## 日本語

- **stdin が開いたままでも shutdown/exit 後に LSP stdio が速やかに終了するようになりました (#5086)** — 順序どおりの `exit` notification 後は新しい input read を開始せず、shutdown response を先に flush し、caller-owned stream を閉じることなく shutdown 前 exit の非ゼロ status を維持します。
