## English

- **`resources/list` responses are now byte-bounded and omission-aware (#4542)** — Pages measure the complete JSON-RPC envelope against an optional `maxBytes` budget and the active HTTP response cap, continue with an opaque cursor before crossing the effective limit, and report bounded counts and reasons for every omitted resource. HTTP JSON-RPC batches also budget the complete response array, including brackets and commas, so multiple large resource pages share the transport cap while preserving every response ID.

## 日本語

- **`resources/list` response を byte 上限と省略通知に対応 (#4542)** — ページは任意の `maxBytes` budget と active HTTP response 上限に対して JSON-RPC envelope 全体を計測し、有効上限の超過前に不透明 cursor で継続するとともに、省略した全 resource の件数と理由を有界に報告します。HTTP JSON-RPC batch でも bracket と comma を含む response 配列全体を budget 対象とするため、複数の大きな resource page が transport 上限を共有し、すべての response ID を保持します。
