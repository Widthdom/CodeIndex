## English

- **Suggestion IDs now remain stable across draft edits (#4588)** — new records use content-independent immutable public IDs, all editable fields participate in a separate `revision_hash`, legacy `hash` values migrate without breaking old references, stale or in-flight concurrent results cannot overwrite a newer revision, and CLI, export, and MCP output expose both identities.

## 日本語

- **draft 編集後も提案 ID が変わらなくなりました (#4588)** — 新規 record は内容と独立した不変の公開 ID を使い、全ての編集対象 field を別の `revision_hash` に反映します。旧 `hash` 値は既存参照を壊さず移行し、stale な編集や送信中の旧結果が新しい revision を上書きすることを防ぎ、CLI・export・MCP 出力で両 identity を公開します。
