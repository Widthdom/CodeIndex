## English

- **Suggestions now support audited manual lifecycle transitions and bounded atomic file exports (#4719)** — maintainers can explicitly move records among validated local/upstream states with actor, reason, timestamp, and revision metadata, while Markdown and issue-draft exports can safely publish up to 16 MiB through no-overwrite or explicit atomic-replacement paths.

## 日本語

- **提案で監査付き手動ライフサイクル遷移と上限付き原子的ファイル出力を利用できるようになりました (#4719)** — メンテナーは actor、reason、timestamp、revision metadata を記録しながら検証済みのローカル／upstream 状態へ明示的に遷移でき、Markdown と issue draft は既存ファイルを既定で保護しつつ、明示的な原子的置換を含む安全な経路で最大 16 MiB まで出力できます。
