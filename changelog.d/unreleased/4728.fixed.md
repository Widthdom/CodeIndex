## English

- **Markdown fence-language markers no longer pollute default unused audits (#4728)** — `unused --lang markdown` now classifies fenced-code markers such as `bash`, `md`, and `python` as documentation syntax and suppresses them by default, while `--all` still returns them for raw auditing.

## 日本語

- **Markdown の fence language marker が既定の unused audit に混入しなくなりました (#4728)** — `unused --lang markdown` は `bash`、`md`、`python` などの fenced-code marker をドキュメント構文として分類して既定では抑制し、raw audit が必要な場合は引き続き `--all` で取得できます。
