## English

- **Watch sub-runs are cancellable without replacing process-global stdout (#4591)** — Ctrl-C, SIGTERM, and embedding-host cancellation now flow through one linked token into active incremental or full-rescan work, including FTS rebuild/optimization and SQLite planner maintenance. Interrupted bulk FTS work restores synchronization triggers and leaves recoverable state for the next run. Index command output is captured through a runner-scoped writer, keeping concurrent and embedded stdout isolated, with deterministic coverage for idle and active cancellation.

## 日本語

- **process-global stdout を置き換えずに watch sub-run をキャンセルできるようになりました (#4591)** — Ctrl-C、SIGTERM、埋め込み host からの cancellation を単一の linked token 経由で実行中の差分更新または full rescan へ伝播し、FTS rebuild / optimization と SQLite planner maintenance も中断します。中断した bulk FTS work は同期 trigger を復元し、次回 run で recovery 可能な状態を残します。index command の出力は runner scope の writer で capture するため、同時実行や埋め込み先の stdout を分離したまま維持でき、idle / active cancellation を決定的なテストで固定しました。
