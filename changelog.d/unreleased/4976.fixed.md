## English

- **Global JSON-envelope preprocessing now preserves option-shaped command data (#4976)** — a separated option value or positional value after `--` that equals `--json-envelope` is no longer consumed as the global envelope flag, while an actual `--json-envelope` option still produces the normal JSON envelope.

## 日本語

- **グローバル JSON envelope の前処理が option 形式の command data を保持するようになりました (#4976)** — 分離形式の option 値または `--` 後の positional 値が `--json-envelope` と同じ場合でもグローバル envelope flag として消費されず、実際の `--json-envelope` option は従来どおり通常の JSON envelope を生成します。
