## English

- **C# nested interpolated templates preserve enclosing symbols (#4729)** — The lexical masker now restores every parent interpolation frame after nested regular, verbatim, or raw strings, so raw SQL and completion templates no longer truncate enclosing class ranges. Calls inside expression-bodied properties and string contents are no longer emitted as phantom declarations, and the C# extraction contract refreshes existing indexes.

## 日本語

- **C# の nested interpolated template が enclosing symbol を維持するようになりました (#4729)** — lexical masker が nested regular / verbatim / raw string の終了時にすべての親 interpolation frame を復元するようになり、raw SQL や completion template によって enclosing class range が途中で切れなくなりました。expression-bodied property や string content 内の call は phantom declaration として抽出されず、C# extraction contract の更新により既存 index も再抽出されます。
