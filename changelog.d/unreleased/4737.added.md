- **CUDA and shader languages now expose bounded reference graphs (#4737)** — CUDA, GLSL, HLSL, Metal, and WGSL now index statically visible calls, CUDA kernel launches, user-defined type uses, resources, bindings, and supported includes, with per-language metadata suppression and explicit conservative readiness semantics.
