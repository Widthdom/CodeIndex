## English

- **Large LSP symbol responses now support bounded progress and cancellation (#4721)** — `workspace/symbol` and `textDocument/documentSymbol` honor partial-result and work-done tokens, stream deterministic chunks under item and byte limits, report truncation and accurate cancelled counts, preserve document-sync notifications and required rejection responses under queue pressure, and return the standard cancellation error when `$/cancelRequest` stops an active request.

## 日本語

- **大きな LSP symbol response が上限付き progress と cancellation に対応しました (#4721)** — `workspace/symbol` と `textDocument/documentSymbol` は partial-result / work-done token を処理し、item・byte 上限内の決定的な chunk を送信して切り詰めと正確な cancellation 済み件数を通知し、queue pressure 下でも document-sync notification と必要な rejection response を保持して、`$/cancelRequest` で active request を停止した場合は標準の cancellation error を返します。
