## English

- **Unified CLI help and completion metadata (#4571)** — command help for shared-parser commands now derives accepted flags and descriptions from the schema used by parser validation and shell completions, while dedicated and nested parsers retain their exact usage syntax instead of showing partial parent-command options. Optional-subcommand completion keeps parent flags available for `recipes` and `suggestions`, nested workspace completion includes clear/deactivate, dependency recovery hints reuse canonical flag spellings, search usage separates query modes, and `status --explain sqlite_connection_policy` documents SQLite/WAL diagnostics.

## 日本語

- **CLI help と completion の metadata を統一しました (#4571)** — 共有 parser を使う command help は parser validation と shell completion が使う schema から受理済み flag と説明を生成し、専用 parser / nested parser は不完全な親 command option を表示せず、正確な usage 構文を維持します。optional-subcommand completion は `recipes` / `suggestions` の親 command flag を維持し、nested workspace completion に clear/deactivate を追加し、dependency recovery hint は canonical な flag 表記を再利用し、search usage は query mode を明確に分離し、`status --explain sqlite_connection_policy` は SQLite / WAL diagnostic を説明します。
