- **Polling watch now follows allowed directory symlinks (#5124)** — `index --watch` polling observes changes beneath directory links allowed by `--follow-symlinks internal|all`, preserves symlink-relative update paths, and bounds cycles and duplicate targets by resolved directory identity.

## 日本語
