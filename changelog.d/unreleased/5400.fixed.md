## English

- **Ordinary dependency evidence respects target identity (#5400)** — CLI/MCP `deps` uses confirmed target and candidate IDs for applicable non-C# references, preventing Java/JavaScript self-calls from creating dependencies on unrelated same-name definitions. Python import/module edges remain visible, while import-binding resolution is distinguished from definition resolution and evidence filters use the selected target's state. Current indexes need no reindex.
