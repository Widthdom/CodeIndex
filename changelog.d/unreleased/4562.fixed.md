## English

- **Conflicting or ineffective output-format options now fail explicitly (#4562)** — `--json` no longer silently loses to CSV, TSV, quickfix, or command-owned JSON schemas, `--pretty` with explicit or implicit NDJSON now points callers to `--json=array --pretty`, while single-document recipe, aggregation, summary, count, and compact JSON outputs remain pretty-printable. Dash-prefixed `--query` values remain literals, and invalid modes, unsupported flags, and command-unsupported formats keep their primary diagnostics instead of being masked by a secondary combination error.

## 日本語

- **競合する、または効果のない出力形式オプションを明示的に拒否するようになりました (#4562)** — `--json` が CSV、TSV、quickfix、またはコマンド固有の JSON schema に黙って負けることがなくなり、明示／暗黙 NDJSON と `--pretty` の組み合わせは `--json=array --pretty` を案内する一方、単一文書の recipe、aggregation、summary、count、compact JSON 出力は pretty-print できます。dash 始まりの `--query` 値を維持し、不正な mode、未対応 flag、command 未対応 format の一次 diagnostics を二次的な組み合わせエラーで覆い隠しません。
