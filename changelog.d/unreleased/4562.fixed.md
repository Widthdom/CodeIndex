## English

- **Conflicting or ineffective output-format options now fail explicitly (#4562)** — `--json` no longer silently loses to CSV, TSV, quickfix, or command-owned JSON schemas, `--pretty` with explicit or implicit NDJSON now points callers to `--json=array --pretty`, dash-prefixed `--query` values remain literals, and pre-command modifiers preserve command-owned structured errors.

## 日本語

- **競合する、または効果のない出力形式オプションを明示的に拒否するようになりました (#4562)** — `--json` が CSV、TSV、quickfix、またはコマンド固有の JSON schema に黙って負けることがなくなり、明示／暗黙 NDJSON と `--pretty` の組み合わせは `--json=array --pretty` を案内し、dash 始まりの `--query` 値とコマンド固有の構造化エラー契約を維持します。
