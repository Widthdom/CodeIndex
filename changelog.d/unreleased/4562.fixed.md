## English

- **Conflicting or ineffective output-format options now fail explicitly (#4562)** — `--json` no longer silently loses to CSV, TSV, or quickfix formats, `--pretty` with NDJSON now returns a command-specific usage error that points callers to `--json=array --pretty`, and `suggestions export` retains its structured JSON usage-error contract.

## 日本語

- **競合する、または効果のない出力形式オプションを明示的に拒否するようになりました (#4562)** — `--json` が CSV、TSV、quickfix 形式に黙って負けることがなくなり、NDJSON と `--pretty` の組み合わせは `--json=array --pretty` を案内するコマンド固有の usage error を返し、`suggestions export` は structured JSON の usage-error 契約を維持します。
