## English

- **Conflicting or ineffective output-format options now fail explicitly (#4562)** — `--json` no longer silently loses to CSV, TSV, or quickfix formats, and `--pretty` with NDJSON now returns a command-specific usage error that points callers to `--json=array --pretty`.

## 日本語

- **競合する、または効果のない出力形式オプションを明示的に拒否するようになりました (#4562)** — `--json` が CSV、TSV、quickfix 形式に黙って負けることがなくなり、NDJSON と `--pretty` の組み合わせは `--json=array --pretty` を案内するコマンド固有の usage error を返します。
