## English

- **Large database comparisons now finish predictably and keep JSON failures structured** — `diff` recognizes the same database through direct, URI, and filesystem aliases with equivalent SQLite snapshot semantics before row enumeration, and uses bounded buffers to recognize separate byte-identical copies without lifting the comparison safety limits. Distinct inputs remain bounded, while `import --check --json` reports comparison-budget exhaustion as a typed `import` error with stable phase, code, root cause, and retry guidance instead of falling through to a generic process failure.

## 日本語

- **大規模 database 比較を予測可能に完了させ、JSON failure を構造化しました** — `diff` は同等の SQLite snapshot semantics を持つ direct path、URI、filesystem alias を通した同一 database を row 列挙前に認識し、比較 safety limit を緩和せず、別 file の byte-identical copy も上限付き buffer で判定します。異なる input は引き続き上限付きで比較し、`import --check --json` の比較 budget 超過は generic な process failure へ落ちず、stable な phase、code、root cause、retry 案内を持つ型付き `import` error として報告します。
