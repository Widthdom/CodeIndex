## English

- **Vacuum now captures physical before sizes at command entry (#5237)** — `vacuum --json` measures the main database, WAL, and SHM before SQLite validation can create sidecars, distinguishes absent from empty sidecars, and exposes separate command-entry, post-open/pre-vacuum, and post-close revalidated post-command observations with bounded unavailable diagnostics without taking an additional post-close dry-run database snapshot. Dry runs anchor revalidation to the logical-metrics source generation, including across atomic path replacement, while immutable dry runs also bracket connection open and fail closed after concurrent source changes.

## 日本語

- **vacuum が物理 before size を command entry で取得するようになりました (#5237)** — `vacuum --json` は SQLite validation が sidecar を作成する前に main database、WAL、SHM を計測し、存在しない sidecar と空の sidecar を区別して、command-entry、post-open / vacuum 前、close 後に再検証する post-command の各 observation を上限付き unavailable diagnostic と共に、close 後に追加の dry-run database snapshot を取得せず分離して公開します。dry-run は atomic path replacement を含めて logical metrics 取得時の source generation に再検証を固定し、immutable dry-run はさらに connection open の前後を同一世代で挟んで並行 source 変更後に fail closed します。
