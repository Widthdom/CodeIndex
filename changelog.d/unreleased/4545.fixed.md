## English

- **JSON-RPC batch items now execute with bounded concurrency and durable cancellation (#4545)** — independent items share the global MCP request limit, queued targets remain cancellable without depending on tombstone capacity or TTL, and pre-dispatch returns release their registrations for safe ID reuse. HTTP authenticates before cancellation handling, extracts cross-frame controls before queue admission, and keeps same-batch controls with their queued target; session mutations and repeated IDs retain input-order semantics, per-item failures stay isolated, and response arrays remain in input order.

## 日本語

- **JSON-RPC batch item を上限付きで並行実行し、queued cancellation を durable にしました (#4545)** — 独立 item は global MCP request 上限を共有し、queued target は tombstone の件数上限や TTL に依存せず cancellation でき、dispatch 前に return した item は登録を解放して ID を安全に再利用できます。HTTP は cancellation 処理前に認証し、cross-frame control は queue admission 前に抽出し、same-batch control は queue 待ち target と同じ batch に残します。session mutation と重複 ID は入力順 semantics を維持し、item ごとの失敗を分離して response array の入力順を保ちます。
