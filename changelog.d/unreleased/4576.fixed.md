## English

- **`status --stale-after` now activates the freshness gate (#4576)** — a valid CLI threshold implies `--check`, always includes the workspace gate even with scoped checks, preserves fresh and stale exit codes, and records the effective threshold plus `explicit` or `implied_by_stale_after` mode in JSON `query_context`.

## 日本語

- **`status --stale-after` が freshness gate を有効化するようになりました (#4576)** — 有効な CLI しきい値は `--check` を暗黙に有効化し、scope 付き check でも workspace gate を必ず含め、fresh / stale の exit code を維持し、JSON の `query_context` に有効なしきい値と `explicit` または `implied_by_stale_after` mode を記録します。
