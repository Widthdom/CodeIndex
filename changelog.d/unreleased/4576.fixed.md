## English

- **`status --stale-after` now activates the freshness gate (#4576)** — a valid CLI threshold implies `--check`, fresh and stale workspaces preserve the check exit-code contract, and JSON records the effective threshold plus `explicit` or `implied_by_stale_after` mode in `query_context`.

## 日本語

- **`status --stale-after` が freshness gate を有効化するようになりました (#4576)** — 有効な CLI しきい値は `--check` を暗黙に有効化し、fresh / stale workspace で check の exit-code 契約を維持し、JSON の `query_context` に有効なしきい値と `explicit` または `implied_by_stale_after` mode を記録します。
