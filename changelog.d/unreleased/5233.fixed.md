## English

- **Explicit projected JSON arrays preserve their schema (#5233)** — `search`, `symbols`, and `files` now keep `--json=array --fields ...` as a bare projected array, including empty and byte-bounded results, while rejecting output combinations that require an incompatible shape. This closes the residual array-selection regression from #5190.

## 日本語

- **明示した投影付き JSON array の schema を維持 (#5233)** — `search`、`symbols`、`files` で `--json=array --fields ...` を指定した場合、空または byte 上限付きの結果を含め、投影済み bare array のまま返すようにしました。非互換な shape を必要とする出力の組み合わせは明示的に拒否します。#5190 に残っていた array 選択の regression を解消しました。
