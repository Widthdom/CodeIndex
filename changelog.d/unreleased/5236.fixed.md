## English

- **Dry-run row operations are now distinct from projected table state (#5236)** — Building on the earlier dry-run mutation estimates from #3569 and #4893, `index --dry-run` reports per-table deletes, inserts/upserts, total row operations, projected final rows, and projected deltas with independent confidence and unknown reasons. Deprecated legacy mutation fields remain explicit total-operation aliases during the compatibility window.

## 日本語

- **dry-run の row operation と予測 table state を分離しました (#5236)** — #3569 と #4893 の従来の dry-run mutation 推定を基礎として、`index --dry-run` は table ごとの delete、insert/upsert、総 row operation、予測最終 row 数、予測 delta を独立した confidence / unknown reason 付きで返します。非推奨の従来 mutation field は互換期間中、明示的な総 operation alias として維持されます。
