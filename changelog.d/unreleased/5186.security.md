## English

- **MCP audit records now preserve authenticated request provenance separately from client metadata (#5186)** — Per-tool JSONL includes bounded `auth_source` and `auth_subject` fields for local stdio, stdio token, HTTP bearer, and explicit anonymous loopback requests. Request-scoped transport identity remains isolated across concurrent, cancelled, timed-out, notification, batch, error, and serialization-failure paths, while compatible `caller` fields remain explicitly client-declared and no token-derived value is logged.

## 日本語

- **MCP 監査レコードで認証済み request provenance を client metadata と分離して保持するようにしました (#5186)** — per-tool JSONL に local stdio、stdio token、HTTP bearer、明示的な anonymous loopback request を示す bounded な `auth_source` / `auth_subject` を追加しました。request-scoped な transport identity は並行、取消、timeout、notification、batch、error、serialization failure の各経路で分離され、互換用の `caller` field は client 自己申告であることを明確にしたまま、token 由来の値を記録しません。
