## English

- **Externally supplied JSON-RPC ids no longer appear raw in telemetry (#4551)** — MCP stderr, activities, metrics, audit records, HTTP request logs, and timeout diagnostics now use process-salted fixed-length opaque tokens with id type and length metadata, while raw ids remain only on the protocol wire and in protocol internals. A process-local distinct-id budget collapses further unseen ids to one salted overflow token so telemetry cardinality stays bounded.

## 日本語

- **外部から渡された JSON-RPC id の生値が telemetry に出力されなくなりました (#4551)** — MCP の stderr、activity、metrics、audit record、HTTP request log、timeout diagnostics は id の型・長さ metadata を伴う process-salted な固定長 opaque token を使用し、生の id は protocol wire と protocol 内部だけに残します。process-local な distinct-id budget を超えた未観測 id は salted overflow token 1 個へ集約し、telemetry cardinality を bounded に保ちます。
