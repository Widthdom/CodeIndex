## English

- **Auth-token audits now rank credential context ahead of structural token noise (#4590)** — Each auth-token child query ranks tightly coupled credential identifiers, runtime header use, and secret-provider symbols before applying its result limit, while comments, documentation/help text, regex definitions, and parser, LSP, syntax-token, or `CancellationToken` contexts are down-ranked. Paired true/false fixtures now enforce top-N precision across bearer/authorization, GitHub/API/access-token, and token-secret searches.
