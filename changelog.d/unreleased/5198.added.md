## English

- **CODEOWNERS files are now first-class searchable repository metadata (#5198)** — cdidx recognizes the three GitHub-supported locations, indexes ordered ownership rules and user/team/email owners for `symbols` and `outline`, keeps raw `search` and candidate `files` queries available, and reports bounded diagnostics for malformed or oversized rules without claiming owner authorization or graph semantics.

## 日本語

- **CODEOWNERS file を first-class の検索可能な repository metadata として扱うようになりました (#5198)** — cdidx は GitHub が対応する3つの location を認識し、順序付き ownership rule と user/team/email owner を `symbols` / `outline` 用に索引します。raw `search` と candidate の `files` query も利用でき、不正または過大な rule には上限付き diagnostic を返しつつ、owner authorization や graph semantics は保証しません。
