## English

- **`audit --all` now runs every registered audit recipe with bounded cross-recipe summaries (#5238)** — Recipes run in deterministic registry-name order with shared search filters, per-query and global row limits, recipe/query attribution, explicit non-unique overlap accounting, bounded JSON/NDJSON output, and partial-failure recovery metadata.

## 日本語

- **`audit --all` で登録済みの全 audit recipe を上限付き cross-recipe summary とともに実行できるようになりました (#5238)** — registry 名の決定的な順序、共通 search filter、query ごとおよび全体の row 上限、recipe/query の帰属、重複を unique 数と誤認しない明示的な集計、上限付き JSON/NDJSON、部分失敗の recovery metadata を提供します。
