## English

- **`audit --all` now runs every registered audit recipe with bounded cross-recipe summaries (#5238)** — Recipes run in deterministic registry-name order with shared search filters and optional exclusion diagnostics, per-query and global row limits, recipe/query attribution and freshness, explicit non-unique overlap accounting, deadline- and byte-bounded JSON/NDJSON output, and failed/partial/omitted recovery metadata.

## 日本語

- **`audit --all` で登録済みの全 audit recipe を上限付き cross-recipe summary とともに実行できるようになりました (#5238)** — registry 名の決定的な順序、共通 search filter と任意の exclusion diagnostic、query ごとおよび全体の row 上限、recipe/query の帰属と freshness、重複を unique 数と誤認しない明示的な集計、deadline と byte 上限付き JSON/NDJSON、failed / partial / omitted の recovery metadata を提供します。
