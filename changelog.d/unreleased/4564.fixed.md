- **JSON query failures now use one versioned error envelope (#4564)** — validation failures for `search`, `find`, and `status`, missing `goto` definitions, and missing or out-of-range `excerpt` coordinates now preserve their documented non-success exit codes while returning parseable JSON with stable `status` and `error_code` fields.
