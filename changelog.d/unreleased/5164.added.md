## English

- **C# top-level program bodies are now actionable synthetic symbols (#5164)** — `outline`, coordinate `inspect`, CLI JSON/compact output, and MCP expose a file-qualified `<top-level>` function with an explicit synthetic marker and snapshot selector; passing that selector to `callees` now round-trips the same file-scoped caller identity without colliding across files, while stale indexes request a reindex.

## 日本語

- **C# top-level program body を操作可能な synthetic symbol として公開するようになりました (#5164)** — `outline`、座標指定 `inspect`、CLI JSON/compact 出力、MCP は、明示的な synthetic marker と snapshot selector を持つ file-qualified な `<top-level>` function を公開します。その selector を `callees` に渡すと file 間で衝突せず同じ file-scoped caller identity を往復でき、stale index には reindex を案内します。
