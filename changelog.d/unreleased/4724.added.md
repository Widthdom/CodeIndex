## English

- **MCP discovery and status responses now offer bounded low-context views (#4724)** — `tools/list` accepts opt-in `format: "compact"` catalogs and exact `names` filters for retrieving full definitions on demand, while the default and explicit `format: "full"` responses remain compatible. The `status` tool now accepts bounded top-level `fields` projection after full or compact formatting, so clients can request only freshness or readiness data without carrying the complete status payload.

## 日本語

- **MCP discovery と status response に上限付きの低 context view を追加しました (#4724)** — `tools/list` は opt-in の `format: "compact"` catalog と exact な `names` filter に対応し、必要な完全定義だけを on-demand で取得できます。既定値および明示的な `format: "full"` response は互換性を維持します。`status` tool は full / compact formatting 後の top-level `fields` projection に対応し、完全な status payload を保持せず freshness や readiness だけを要求できます。
