## English

- **Made the process-wide SQLite schema cache immutable and lifecycle-bounded (#4554)** — column and index lookups now publish frozen snapshots that callers cannot corrupt, while per-path shared state remains available to active database contexts and is released when the final owner is disposed.

## 日本語

- **プロセス全体の SQLite schema cache を immutable かつ lifecycle 上限付きにしました (#4554)** — column / index lookup は caller が破壊できない frozen snapshot を公開し、path ごとの共有状態は有効な database context が存在する間だけ維持して最後の owner の dispose 時に解放します。
