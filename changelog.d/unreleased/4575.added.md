## English

- **Added conventional `help <command>` routing (#4575)** — `cdidx help <command> [subcommand]` now renders the existing command help without dispatching the target; missing and unknown targets return usage exit `1` with stable error codes and nearest command/subcommand suggestions.

## 日本語

- **conventional な `help <command>` routing を追加しました (#4575)** — `cdidx help <command> [subcommand]` は target を dispatch せず既存 command help を表示します。target の欠落・未検出は安定した error code と最も近い command / subcommand の候補を添えて usage 終了コード `1` を返します。
