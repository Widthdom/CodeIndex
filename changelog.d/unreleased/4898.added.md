## English

- **MCP tools now publish typed structured-output schemas (#4898)** — Every full `tools/list` entry advertises a bounded draft 2020-12 `outputSchema` covering tool-specific required fields, versioned success and error results, rows, readiness, pagination and truncation, and warnings. Catalog construction fails when a newly registered tool lacks a schema, and regression coverage validates actual success and typed-error results for all 24 tools plus empty, partial, incomplete, and cross-tool cases.

## 日本語

- **MCP tool が型付き structured-output schema を公開するようになりました (#4898)** — full `tools/list` の全 entry が、tool 固有の required field、version 付き success / error result、row、readiness、pagination / truncation、warning を表す bounded な draft 2020-12 `outputSchema` を公開します。新しく登録した tool に schema がない場合は catalog 構築を失敗させ、回帰テストで全24 tool の実際の success / typed-error result と empty、partial、不完全、別 tool の case を検証します。
