## English

- **MCP tools now publish typed structured-output schemas (#4898)** — Every full `tools/list` entry advertises a bounded draft 2020-12 `outputSchema` covering versioned success results, rows, readiness, pagination and truncation, warnings, and typed tool errors. Catalog construction fails when a newly registered tool lacks a schema, and regression coverage validates representative actual success, empty, partial, and error results.

## 日本語

- **MCP tool が型付き structured-output schema を公開するようになりました (#4898)** — full `tools/list` の全 entry が、version 付き success result、row、readiness、pagination / truncation、warning、型付き tool error を表す件数上限を考慮した draft 2020-12 `outputSchema` を公開します。新しく登録した tool に schema がない場合は catalog 構築を失敗させ、回帰テストで実際の success、empty、partial、error result の代表例を検証します。
