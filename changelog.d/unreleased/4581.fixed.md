## English

- **Limited hotspot queries now use bounded maintained SQL aggregates (#4581)** — indexing maintains compact per-file logical-reference totals, and symbol/file/name hotspot ranking selects an index-ordered bounded candidate frontier before ambiguity joins instead of regrouping the complete raw reference graph for every query. Logical-site aliases are deduplicated consistently, cross-file context/identity mutations refresh or demote trust transactionally, and cancellation interrupts in-flight SQLite aggregate work.

## 日本語

- **limit 付き hotspot query が bounded な maintained SQL aggregate を使うようになりました (#4581)** — indexing が file 単位の compact な logical-reference totals を維持し、symbol/file/name の hotspot ranking は完全な raw reference graph を毎回 regroup せず、index 順の bounded candidate frontier を曖昧性判定の前に選択します。logical-site alias は一貫して重複排除し、cross-file context / identity の変更時は transaction 内で trust を再計算または降格し、cancellation は実行中の SQLite aggregate 処理を中断します。
