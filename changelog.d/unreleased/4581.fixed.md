## English

- **Limited hotspot queries now use bounded maintained SQL aggregates (#4581)** — indexing maintains compact per-file logical-reference totals, and symbol/file/name hotspot ranking uses indexable joins plus SQL ordering and limits instead of regrouping the complete raw reference graph for every query.

## 日本語

- **limit 付き hotspot query が bounded な maintained SQL aggregate を使うようになりました (#4581)** — indexing が file 単位の compact な logical-reference totals を維持し、symbol/file/name の hotspot ranking は query ごとに complete raw reference graph を regroup せず、索引可能な join と SQL ordering / limit を使います。
