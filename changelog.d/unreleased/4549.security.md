## English

- **Loopback HTTP MCP now uses bearer authentication and browser-boundary checks by default (#4549)** — HTTP startup requires a bearer token unless loopback-only unsafe mode is explicitly selected, rejects untrusted Origin and CORS preflight requests, and accepts only strict UTF-8 `application/json` POST bodies.

## 日本語

- **loopback HTTP MCP でも bearer 認証と browser boundary 検証が既定になりました (#4549)** — HTTP 起動時は loopback 専用 unsafe mode を明示選択しない限り bearer token が必要で、信頼されない Origin と CORS preflight を拒否し、strict UTF-8 の `application/json` POST body だけを受理します。
