## English

- **Hardened MCP rate limiting before tool-call validation (#4547)** — Direct `tools/call` requests now enter rate limiting before detailed validation, while unrecognized direct and `batch_query` slot names share bounded keys per caller. Bucket-cap responses report the earliest real recovery delay, preventing malformed requests or high-cardinality names from bypassing protection or starving legitimate clients.

## 日本語

- **MCP の tool-call 検証前レート制限を強化しました (#4547)** — direct な `tools/call` request は詳細検証前にレート制限へ入り、未認識の direct 名と `batch_query` slot 名は caller ごとの bounded key を共有します。bucket 上限時の応答は実際の最短回復時間を返すため、不正 request や高 cardinality 名による保護回避と正規 client の枯渇を防ぎます。
