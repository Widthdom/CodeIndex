## English

- **Database permission hardening failures are now portable and auditable (#4559)** — Unix mode operations default to a warning-producing `best_effort` policy so SQLite-capable FUSE and network mounts remain usable, while `CDIDX_DB_PERMISSION_POLICY=strict` requires enforcement. Status JSON exposes the effective policy and support-safe machine-readable diagnostics.

## 日本語

- **database permission hardening の失敗を portable かつ監査可能にしました (#4559)** — Unix mode 操作は既定で warning を返す `best_effort` policy となり、SQLite を利用できる FUSE / network mount を継続利用できます。`CDIDX_DB_PERMISSION_POLICY=strict` では enforcement を必須化し、status JSON は有効な policy と support-safe な機械可読 diagnostic を公開します。
