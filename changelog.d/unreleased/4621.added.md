## English

- **Added symmetric `find --context` windows (#4621)** — `find --context <n>` now sets both snippet sides, while explicit `--before` and `--after` independently override their corresponding sides regardless of option order. Values share the existing 1,000-line context bound, option-shaped literal queries remain literal, and shared help, shell completions, direct parsing, and JSON-lines batch dispatch expose the same contract.

## 日本語

- **対称な `find --context` window を追加しました (#4621)** — `find --context <n>` は snippet の前後を同じ行数に設定し、明示した `--before` / `--after` は引数順にかかわらず対応する側だけを上書きします。値には既存の context と同じ 1,000 行の上限を適用し、option に似た literal query は literal のまま扱います。共有 help、shell completion、直接 parsing、JSON Lines batch dispatch が同じ契約を公開します。
