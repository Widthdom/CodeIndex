## English

- **Validated HTTP MCP resource limits and isolated SSE admission (#4550)** — Every present HTTP limit environment variable must now be a positive integer in its documented range or startup fails with the exact variable and accepted range. Long-lived `/events` connections use a separate bounded admission gate, so stream saturation cannot consume POST handler capacity, and `/healthz` reports both effective capacities.

## 日本語

- **HTTP MCP resource limit を検証し SSE admission を分離 (#4550)** — 設定済みの HTTP limit 環境変数は、文書化された範囲内の正の整数でなければ、正確な変数名と受理範囲を示して起動に失敗するようになりました。長寿命 `/events` 接続は独立した有界 admission gate を使うため、stream 飽和が POST handler capacity を消費せず、`/healthz` は両方の有効 capacity を報告します。
