## English

- **Python type declarations now use semantic symbol kinds (#4615)** — PEP 695 aliases plus `TypeAlias` and `NewType` declarations are stored as `typealias`, while `TypeVar`, `ParamSpec`, and `TypeVarTuple` declarations use `type_parameter`; import-only queries now exclude these local declarations, both kinds map to the broad `type` compatibility family, and a normal index refresh migrates unchanged Python files from the previous extractor contract.

## 日本語

- **Python の型宣言が semantic な symbol kind を使うようになりました (#4615)** — PEP 695 alias と `TypeAlias` / `NewType` declaration は `typealias`、`TypeVar` / `ParamSpec` / `TypeVarTuple` declaration は `type_parameter` として保存されるため、import-only query からローカル宣言が除外され、両 kind は広い `type` compatibility family に mapping されます。また、通常の index refresh で未変更の Python file も旧 extractor contract から移行します。
