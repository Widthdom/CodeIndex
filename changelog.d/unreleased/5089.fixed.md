- **C# `unused` now recognizes private fields used by sibling partial declarations (#5089)** — partial-type source is reconstructed without overlapping duplicate lines and lexically masked once, so raw-string chunk boundaries no longer hide PascalCase static readonly collection reads or writes while unrelated same-named and genuinely unused fields remain actionable.
