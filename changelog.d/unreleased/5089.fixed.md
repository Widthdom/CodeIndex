## English

- **C# `unused` now recognizes private fields used by sibling partial declarations (#5089)** — partial-type source is reconstructed per peer file in a linear pass without overlapping duplicate lines and lexically masked once, so raw-string chunk boundaries no longer hide PascalCase static readonly collection reads or writes while unrelated same-named and genuinely unused fields remain actionable. Missing chunk content no longer suppresses text retained by an overlapping successor, and legacy read-only schemas without `chunk_index` also recognize sibling use through a deterministic line-ordered fallback.

## 日本語

- **C# `unused` が sibling partial declaration で使用される private field を認識するようになりました (#5089)** — peer file ごとに partial type の source を線形 pass で重複行なしに再構成してから一度だけ lexical masking するため、raw string の chunk 境界によって PascalCase static readonly collection の read / write が隠れなくなり、無関係な同名 field と本当に未使用の field は引き続き actionable です。欠損 chunk content が重複する後続 chunk に残る text を抑制しなくなり、`chunk_index` のない read-only legacy schema も決定的な line-order fallback で sibling use を認識します。
