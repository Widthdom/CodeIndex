## English

- **High-volume query outputs now share bounded projections and stable pagination (#4585)** — `definition`, `find`, `status`, `hotspots`, `references`, `callers`, `callees`, `impact`, and `map` accept shared field projection and opaque response cursors, report returned/total/omitted counts, and can enforce a whole-response JSON byte budget. Compact location responses keep their established top-level keys and lightweight rows while gaining the shared metadata; compact and aliased commands plus read-only batch children use the same hard cap. Nested graph and map section collections page as rows with collection-specific totals, late pages push offsets into the query layer, scalar map projections skip unused ranked sections, and explicit definition bodies remain available through `body`, `body_content`, and `all` projections while excluded bodies are not materialized.
- **Adversarial edge cases retain their response contracts (#4585)** — impact definition cursors page only definitions without changing caller/fallback mode; plain compact maps preserve their section arrays; conflicting map shape controls fail explicitly; compact explicit body fields override compact defaults; diagnostics become metadata control records; and parser/capture errors never escape the requested hard byte cap.

## 日本語

- **高ボリューム query 出力で bounded projection と安定した pagination を共有するようになりました (#4585)** — `definition`、`find`、`status`、`hotspots`、`references`、`callers`、`callees`、`impact`、`map` は共通の field projection と opaque な response cursor を受け付け、返却 / 総 / 省略件数を報告し、JSON 応答全体の byte budget を適用できます。compact location 応答は既存のトップレベル key と軽量 row を維持したまま共通 metadata を追加し、compact / alias command と read-only batch の子 command にも同じ hard cap を適用します。nested graph collection と map section collection は collection ごとの総件数を持つ row としてページングされ、後続ページの offset は query layer へ渡されます。scalar map projection は不要な ranking section を構築せず、明示的な definition body は `body`、`body_content`、`all` projection で保持される一方、除外された body は取得されません。
- **adversarial な edge case でも response 契約を維持します (#4585)** — impact definition cursor は caller / fallback mode を変えず definition だけをページングし、通常の compact map は section array を維持します。競合する map shape control は明示的に失敗し、compact でも明示 body field を優先します。diagnostic は metadata control record となり、parser / capture error が指定された hard byte cap を超えることもありません。
