## English

- **Direct graph commands can now consume generation-bound selectors emitted by `inspect` (#5187)** — CLI and MCP references, callers, callees, and impact queries can select one exact symbol ID without falling back to same-name aggregation. Bare-name unions now expose explicit identity scope and candidate selectors, while selector validation, filters, structured fields, and cursors preserve the active index generation.

## 日本語

- **direct graph command が `inspect` の generation-bound selector を利用できるようになりました (#5187)** — CLI / MCP の references、callers、callees、impact query は 1 件の正確な symbol ID を選択でき、同名集約へ fallback しません。bare-name の和集合は identity scope と candidate selector を明示し、selector validation、filter、structured field、cursor は active index generation を維持します。
