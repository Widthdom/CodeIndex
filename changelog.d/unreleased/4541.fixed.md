## English

- **`resources/list` now uses generation-aware keyset cursors (#4541)** — Opaque, bounded cursors resume from a stable file anchor, file mutations return an explicit restart-required stale-index error, and mutable read-only legacy databases require migration instead of silently treating missing generation tracking as generation zero. Explicit immutable legacy snapshots remain safely pageable.

## 日本語

- **`resources/list` を世代対応 keyset cursor へ変更 (#4541)** — 不透明かつ有界な cursor が安定した file anchor から再開し、ファイル変更時は再開必須の stale-index error を返します。世代追跡のない変更可能な read-only legacy DB は世代 0 とみなさず migration を要求し、明示的な immutable legacy snapshot は安全にページングできます。
