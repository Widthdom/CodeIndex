## English

- **`find --all` now makes partial row and count scans explicit (#4578)** — JSON rows end with terminal scan metadata, count objects carry the same authority and recovery state, and safety-cap truncation exits with code 11 unless callers explicitly pass `--allow-partial`.

## 日本語

- **`find --all` が row / count の部分 scan を明示するようになりました (#4578)** — JSON row は終端 scan metadata で終了し、count object も同じ authority / recovery 状態を持ちます。safety cap による切り詰めは、caller が `--allow-partial` を明示しない限り終了コード 11 を返します。
