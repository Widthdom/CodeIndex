- **Impact cycle detection now requires a real canonical graph edge (#4847)** — `impact` carries resolved symbol IDs through every traversal hop, so consecutive methods with the same display name no longer create false singleton cycles while direct recursion and real multi-node cycles remain visible. Structured caller, path, and cycle output now includes disambiguating symbol identities.
