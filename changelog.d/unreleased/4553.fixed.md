## English

- **Incomplete MCP audit shutdowns are now observable and optionally enforceable (#4553)** — audit diagnostics track lifetime queued and written records plus a distinct shutdown-deadline abandoned snapshot, and a bounded path-free warning is emitted when the drain deadline expires. `--audit-log-strict` promotes an otherwise-successful MCP session to runtime exit code 10 after an incomplete flush while preserving an existing nonzero exit.

## 日本語

- **MCP audit shutdown の未完了を観測し、必要に応じて強制できるようにしました (#4553)** — audit 診断で lifetime の queued / written record と、通常の drop とは別の shutdown deadline abandoned snapshot を追跡し、drain deadline 超過時には path を含まない bounded warning を出力します。`--audit-log-strict` は不完全な flush の後、正常終了するはずだった MCP session だけを runtime exit code 10 に昇格し、既存の nonzero exit は保持します。
