## English

- **Audit and recipe SARIF now honor exact JSON byte budgets (#4903)** — `--max-json-bytes` measures the complete UTF-8 SARIF document, including JSON escaping and the final newline, before writing stdout. When the full report does not fit, cdidx emits schema-valid SARIF by omitting only whole trailing results and records source/emitted/omitted counts, the byte-budget strategy, and replay guidance while preserving emitted rules and locations. A budget below the minimum complete zero-result document fails before stdout instead of producing partial JSON.

## 日本語

- **audit / recipe の SARIF が正確な JSON byte budget を守るようになりました (#4903)** — `--max-json-bytes` は stdout を書く前に、JSON escape と末尾改行を含む完全な UTF-8 SARIF document を計測します。report 全体が収まらない場合は、末尾の result だけを1件単位で省略し、出力済みの rule / location を維持した schema-valid SARIF を返します。source / emitted / omitted count、byte-budget strategy、replay guidance も記録し、result 0件の完全な document の最小値にも満たない budget では partial JSON を出さず stdout 前に失敗します。
