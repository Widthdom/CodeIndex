## English

- Codex can now initialize the cdidx MCP server and enumerate its tools. The server negotiates the `2025-06-18` protocol version used by current Codex clients while retaining the older `2025-03-26` and `2024-11-05` versions. The setup guide now uses the shared `config.toml` / `codex mcp add` configuration and explains that a new Codex session is required after registration.

## 日本語

- Codex から cdidx MCP サーバーを初期化し、ツール一覧を取得できるようになりました。現在の Codex client が使用する protocol version `2025-06-18` を交渉対象に追加し、従来の `2025-03-26` と `2024-11-05` も維持しています。セットアップガイドを共有の `config.toml` / `codex mcp add` 設定に更新し、登録後は Codex の新しい session が必要なことを明記しました。
