## English

- **Shared pre-commit hooks now index the worktree that invoked Git (#5087)** — installed hooks keep the trusted Git and cdidx executables pinned, resolve the active worktree root at execution time without losing trailing line breaks, fail with actionable guidance when resolution is unavailable, reject missing, untrusted, or line-breaking pinned Git paths, preserve Windows Git-Bash path round-tripping, and migrate older installer-worktree-pinned managed hooks on reinstall.

## 日本語

- **共有 pre-commit hook が Git を呼び出した worktree を index するようになりました (#5087)** — インストール済み hook は信頼済み Git と cdidx の executable 固定を維持しつつ、末尾の改行を失わずに実行時の active worktree root を解決します。解決できない場合は対応方法を示して失敗し、消失、信頼できない、または改行を含む固定済み Git path を拒否します。Windows Git Bash path の round-trip も維持し、installer worktree を固定していた旧 managed hook は再インストール時に移行します。
