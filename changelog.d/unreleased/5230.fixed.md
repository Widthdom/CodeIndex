## English

- **Truncated discovery NDJSON now exposes resumable cursors (#5230)** — Raw `search`, `symbols`, and `files` terminal records include a stable, generation-bound `next_cursor` after the last emitted row by reusing the response-v2 contract from #4730. Continuation rejects changed filters and stale indexes, advances by the actual byte-budgeted row count, omits cursors on final and zero-result pages, and reports a machine-readable reason when selectors, pagination-window exhaustion, or a concurrent index-generation change makes safe progress impossible.

## 日本語

- **切り詰められた discovery NDJSON が再開用 cursor を公開するようになりました (#5230)** — raw `search`、`symbols`、`files` の terminal record は、#4730 の response-v2 契約を再利用し、最後に出力した row の後から再開できる安定した generation-bound `next_cursor` を含みます。continuation は filter 変更と stale index を拒否し、byte budget 内で実際に出力した row 数だけ進みます。最終 page と 0 件 page では cursor を省略し、selector、pagination-window 枯渇、同時発生した index-generation 変更により安全に進められない場合は機械可読な理由を報告します。
