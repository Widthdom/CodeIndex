## English

- **Repository-wide literal find now uses an indexed candidate path (#4725)** — `find --all` uses a synchronized trigram index for safe ASCII literals before re-verifying candidate lines, while regex, normalized exact, short, non-ASCII, legacy, unsynchronized, and actively rebuilding index queries report an explicit bounded-scan fallback.
