## English

- **LSP position-file reads remain bounded when files grow concurrently (#4750)** — disk-backed position-line caching now streams through the 4 MiB byte limit, preserves multibyte text across read boundaries, and returns `position_file_too_large` before over-limit bytes are decoded.

## 日本語

- **file が同時に増大しても LSP position-file read が上限内に収まるようになりました (#4750)** — disk 上の position-line cache は 4 MiB の byte 上限を streaming 中も強制し、read 境界をまたぐ multibyte text を維持しながら、上限超過 byte の decode 前に `position_file_too_large` を返します。
