## English

- **Explicit `index --files` selections now fail atomically when any input is invalid (#5091, #5122)** — real and dry-run updates validate every directly supplied token before writing, return bounded structured reasons for rejected or duplicate inputs, and leave the database unchanged instead of silently succeeding with a partial or empty selection. A bare `--files` is rejected, while paths derived by `--project` retain their established scoped-filtering behavior. Windows 8.3 ancestor aliases canonicalize to the established database spelling. Indexed control files that become directories, FIFOs, or policy-disallowed symlinks remain cleanup tombstones and are never opened or followed; TypeScript configuration reads honor `none` / `internal` / `all` and securely open only regular resolved targets. Internal-symlink containment compares case-only root-prefix components in their parent directory namespaces, so a case-insensitive project mount cannot admit a distinct sibling from a case-sensitive parent. Polling watch excludes resolved aliases of database artifacts and ancestor-ignore aliases while retaining ordinary allowed file symlinks, and a rejected watch-generated batch falls back to one full-workspace rescan so valid sibling changes are reconciled.
