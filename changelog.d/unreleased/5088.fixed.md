## English

- **`index --watch` no longer reindexes after its own atomic lock-info writes (#5088)** — watch now derives exact database, sidecar, lock, lock-info, and sibling atomic-temp recognition from `AtomicFileWriter`'s filename pattern before event coalescing, while unrelated user `.tmp` and `.cdidx-*` files continue through normal source membership.

## 日本語

- **`index --watch` が自身の lock-info atomic write 後に再 index しなくなりました (#5088)** — watch は event coalescing 前に、database、sidecar、lock、lock-info、および sibling atomic temp の正確な判定を `AtomicFileWriter` の filename pattern から導出するようになり、無関係な user `.tmp` / `.cdidx-*` file は引き続き通常の source membership に従います。
