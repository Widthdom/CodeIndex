## English

- **Doctor environment inventories are now filterable and byte-bounded, and license output is available as structured JSON (#4713)** — `doctor --env-inventory=full` accepts domain, category, and sensitivity filters plus a whole-document `--max-json-bytes` limit, while `license --json` exposes stable versioned license, commercial-use, trademark, and controlling-document fields.

## 日本語

- **doctor の environment inventory を filter・byte 制限でき、license を structured JSON で取得できるようになりました (#4713)** — `doctor --env-inventory=full` は domain、category、sensitivity filter と文書全体の `--max-json-bytes` 上限を受け付け、`license --json` は version 付きで安定した license、commercial-use、trademark、controlling-document field を返します。
