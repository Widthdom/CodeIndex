## English

- **Report JSON keeps a safe artifact handle when paths are redacted (#4718)** — `report --json` now returns the generated bundle basename in `output_path`, including with `--redact-paths`, while diagnostic database and parent-directory paths remain redacted.

## 日本語

- **path を伏字化しても report JSON が安全な artifact handle を保持するようになりました (#4718)** — `report --json` は `--redact-paths` の指定時を含め、生成した bundle の basename を `output_path` に返すようになりました。診断用 database path と親 directory path は引き続き伏字化されます。
