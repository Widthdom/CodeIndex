## English

- **A per-file extraction failure no longer hides every successful graph edge or exits as an unconditional success (#4609)** — Full scans and scoped updates commit successful file generations, expose bounded phase-aware file errors, persist completeness separately from freshness, and return partial-result exit code `11` unless `--allow-partial` is explicit. Full-scan JSON also distinguishes extracted from persisted counts. Later scoped updates revalidate the full workspace until the failed file recovers, preventing unrelated updates from clearing the failure and restoring readiness without a rebuild.

## 日本語

- **1ファイルの抽出失敗で全成功 graph edge が隠れたり無条件に成功終了したりしなくなりました (#4609)** — full scan と scoped update は成功した file generation を commit し、上限付きの phase-aware file error を公開し、completeness を freshness と別に永続化します。`--allow-partial` を明示しない限り partial-result 終了コード `11` を返し、full-scan JSON は extracted count と persisted count も区別します。失敗 file が回復するまで後続の scoped update は workspace 全体を再検証し、無関係な update による failure 消去を防ぎつつ rebuild なしで readiness を復元します。
