## English

- **SQLite migrations now track transaction and foreign-key ownership explicitly (#4560)** — opportunistic read migrations detect caller-owned transactions before opening their own transaction, unrelated `BEGIN` errors propagate without partial DDL, and table rebuilds verify foreign keys are disabled before `BEGIN` and restore the original effective mode after success or rollback.

## 日本語

- **SQLite migration が transaction と foreign key の所有権を明示的に追跡するようになりました (#4560)** — opportunistic read migration は独自 transaction を開始する前に caller-owned transaction を検出し、無関係な `BEGIN` error では部分的な DDL を実行せず例外を伝播します。table rebuild は `BEGIN` 前に foreign key の無効状態を検証し、成功時・rollback 時のどちらでも元の実効 mode を復元します。
