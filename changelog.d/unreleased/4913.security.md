## English

- **Unsafe-relaxed JSON audits now expose explicit trust-boundary evidence (#4913)** — JSON read/write recipe results classify controlled private-local writers, external or public writers, untrusted parsers, and ambiguous boundaries from bounded source-proximate origin, direction, sensitivity, trust, and rationale annotations. Trust evidence must be a lexically verified C# line comment bound to the next operation across line, statement, expression, control-flow, and comma-separated boundaries, `review_required` and mixed-boundary rows remain conservatively ambiguous, bounded prefix caching is order-independent, projected outputs skip discarded source work, and classifications never suppress the underlying finding.
