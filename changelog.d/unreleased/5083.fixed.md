## English

- **Inherited batch databases now keep status provenance consistent (#5083)** — child commands that omit `--db` now inherit the batch database before option and JSON-envelope resolution, so data, database metadata, project roots, Git HEADs, and freshness fields no longer mix repositories; child-explicit overrides remain isolated to their own records.

## 日本語

- **batch から継承した database で status provenance が一貫するようになりました (#5083)** — `--db` を省略した child command は option / JSON-envelope 解決より前に batch database を継承するため、data、database metadata、project root、Git HEAD、freshness field が別 repository と混在しなくなり、child が明示した override はその record だけに分離されます。
