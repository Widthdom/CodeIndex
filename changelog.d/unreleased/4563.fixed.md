## English

- **Discovery JSON now keeps its selected schema and reports generated-file filtering (#4563)** — `symbols` and `files` preserve raw NDJSON or array output across zero and byte-capped results, including trust diagnostics on diagnostic-only zero-result arrays and exact byte boundaries. DB-backed discovery query contexts, file counts, and every repository-map JSON format expose schema-aware generated-code policy/availability and excluded generated-file counts, while legacy schemas report a requested filter and count as unavailable instead of claiming exclusion occurred.
