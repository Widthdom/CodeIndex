## English

- **Discovery JSON now keeps its selected schema and reports generated-file filtering (#4563)** — `symbols` and `files` preserve raw NDJSON or array output across zero and byte-capped results, including trust diagnostics and exact byte boundaries. File counts and every repository-map JSON format expose the generated-code policy and excluded generated-file count, while legacy schemas report the filter and count as unavailable instead of claiming exclusion occurred.

## 日本語

- **discovery JSON の選択済み schema を維持し generated file の除外情報を報告 (#4563)** — `symbols` と `files` は 0 件時および byte cap 到達時も trust diagnostics と正確な byte 境界を含めて raw NDJSON または array の形状を維持します。file count とすべての repository-map JSON format は generated-code policy と除外された generated file 数を返し、legacy schema では除外済みと誤認させず filter / count を unavailable として報告します。
