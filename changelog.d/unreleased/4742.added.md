## English

- **Reference graphs now cover Verilog, SystemVerilog, and VHDL (#4742)** — HDL indexing emits bounded, syntax-visible hierarchy, package/import/use, architecture/entity, and scope-aware known same-file signal/type edges for `references` and applicable graph queries. Existing indexes are automatically refreshed by the next full scan before graph readiness is restored; scoped updates and graph queries remain explicitly degraded while that refresh is pending.

## 日本語

- **Verilog、SystemVerilog、VHDL が reference graph に対応しました (#4742)** — HDL の索引作成で、構文上確認できる hierarchy、package/import/use、architecture/entity、および同一ファイル内の scope-aware な既知 signal/type edge を上限付きで出力し、`references` と対応する graph query から利用できます。既存 index は次回 full scan で自動更新され、その完了後に graph readiness を復元します。それまでの scoped update と graph query は明示的に degraded として扱います。
