## English

- **Scan, status, and watch now share membership and invalidation rules (#4592)** — `.cdidx` sidecars are consistently excluded from indexed source membership, while ignore files and workspace pattern/plugin inputs bypass watch filtering long enough to trigger a debounced full scan. Subproject watches observe ancestor ignore files. Extractor reconciliation refreshes the process registry generation, disables unchanged-file reuse, unloads prior workspace plugins, and reloads current pattern/plugin inputs while preserving explicitly registered host extractors, so persisted rows are regenerated even for same-extension edits. Plugin assemblies are loaded without retaining a Windows file lock, allowing refreshes to remove or replace them. Ignore/unignore plus pattern edits, deletion, and plugin removal coverage keep reconciliation behavior aligned across all three paths.

## 日本語

- **scan、status、watch が membership と invalidation rule を共有するようになりました (#4592)** — `.cdidx` sidecar を indexed source membership から一貫して除外しつつ、ignore file と workspace の pattern / plugin 入力は watch filter を通過して debounce 付き full scan を起動し、subproject watch は ancestor ignore file も監視します。extractor reconciliation は process registry の generation を更新して unchanged-file reuse を無効化し、明示的に登録された host extractor を維持しながら以前の workspace plugin を unload して現在の pattern / plugin 入力を再読込するため、同一 extension の編集でも persisted row を再生成します。plugin assembly は Windows の file lock を保持しない形で読み込まれるため、refresh 時に削除・置換できます。ignore / unignore、pattern 編集・削除、plugin 削除を検証し、3 経路の reconciliation 動作を揃えました。
