## English

- **`cdidx report` now includes the failure that recommended running it (#4586)** — unhandled CLI failures save one bounded, redacted event before printing the report guidance, and the next report includes its timestamp, binary details, command and exception categories, exit code, and sanitized diagnostics even when lifecycle logging is disabled, without recording literal arguments.

## 日本語

- **`cdidx report` が実行案内の原因となった失敗を同梱するようになりました (#4586)** — CLI の想定外例外では report の案内表示前に上限付き・匿名化済みイベントを 1 件保存し、ライフサイクルログが無効でも次の report に時刻、binary 情報、command / exception category、exit code、匿名化済み diagnostics を具体的な引数なしで同梱します。
