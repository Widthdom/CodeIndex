## English

- **Query-only SQLite operations no longer mutate index state (#4557)** — Database callers now declare query, indexing, migration, or repair intent. Query-only CLI, LSP, export, dry-run, and MCP paths skip persistent pragmas and opportunistic migrations, preserve database and sidecar artifacts through generation-validated private WAL snapshots, refresh long-lived readers when the source changes, and only report interrupted batches. Cross-database dependency targets use the same snapshot lease and release it after the attaching connection closes; persistent snapshot-copy I/O failures now report temporary-storage remediation instead of WAL churn. Readiness demotion runs solely from the explicit rebuild repair path.
