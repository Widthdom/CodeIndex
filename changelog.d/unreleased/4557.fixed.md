## English

- **Query-only SQLite operations no longer mutate index state (#4557)** — Database callers now declare query, indexing, migration, or repair intent. Query-only CLI, LSP, export, dry-run, and MCP paths skip persistent pragmas and opportunistic migrations, preserve database and sidecar artifacts through immutable checkpointed-WAL opens or stable private hot-WAL snapshots, and only report interrupted batches. Readiness demotion now runs solely from the explicit rebuild repair path.

- **query-only の SQLite 操作が index state を変更しないように修正 (#4557)** — database caller が query、indexing、migration、repair の intent を明示するようにしました。query-only の CLI、LSP、export、dry-run、MCP path は永続 pragma と opportunistic migration を skip し、checkpoint 済み WAL の immutable open または安定した private hot-WAL snapshot で database / sidecar artifact を保持して、interrupted batch は報告だけ行います。readiness demotion は明示的な rebuild repair path からのみ実行します。
