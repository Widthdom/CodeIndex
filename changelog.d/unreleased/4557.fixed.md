## English

- **Query-only SQLite operations no longer mutate index state (#4557)** — Database callers now declare query, indexing, migration, or repair intent. Query-only CLI, LSP, export, dry-run, and MCP paths open SQLite read-only from the first attempt, skip persistent pragmas and opportunistic migrations, and only report interrupted batches. Readiness demotion now runs solely from the explicit rebuild repair path.
